2. 参数计算方法

以下采用血浆/血清浓度的非房室分析（NCA）框架。以给药时刻为 t = 0，tᵢ 为实际采样时间，Cᵢ 为对应可用于分析的浓度；Dose 为给药剂量，τ 为给药间隔。公式主要用于理解和独立 QC，不代替项目配置。

2.1 直接从观测浓度读取

Cmax峰浓度
Cmax = max(Cᵢ)

分析时间范围内观测到的最大浓度，不需要拟合；若存在并列最大值，Tmax 的取值规则应在分析计划中明确。

Tmax达峰时间
Tmax = time at observed Cmax

对应 Cmax 的采样时间。Phoenix NCA 在并列峰值时选择第一次出现的时间；不是通过曲线插值得到的理论达峰时刻。

Ctrough谷浓度
Ctrough ≈ 给药间隔末端或下一次给药前的浓度

通常取规定的给药前样本或 τ 时点浓度；实际采用观测值还是估算值依 SAP / PK 分析计划。Ctrough 不必然等于给药间隔内最低的 Cmin。

2.2 先计算曲线下面积（AUC）

相邻两个时间点的面积先逐段计算，再在指定区间求和。常用方法如下：

线性梯形法Linear trapezoidal
AUCᵢ = (Cᵢ + Cᵢ₊₁) / 2 × (tᵢ₊₁ − tᵢ)

适用于线性计算规则下的相邻采样区间。

对数梯形法Log trapezoidal
AUCᵢ = (Cᵢ − Cᵢ₊₁) / ln(Cᵢ / Cᵢ₊₁) × (tᵢ₊₁ − tᵢ)

通常用于浓度下降且两端浓度均为正、不相等的区间。常见配置为 Linear-up / Log-down，但不能默认所有项目相同；不满足对数法计算条件时按软件规则使用线性法。

AUClst0 至最后可测定浓度时点
AUClst = Σ AUCᵢ，积分范围为 0 → tlast

tlast 为最后可测定浓度对应时间。AUClst 不等于积分到最后一次采样时间的 AUCall，尤其当末次样本为 BQL 时。

AUCtau一个给药间隔
AUCtau = ∫₀^τ C(t) dt

积分区间为本次给药至 τ；通常用于多次给药/稳态评估。若 τ 处没有观测浓度，可能需要插值或外推，能否计算取决于分析规则和数据覆盖范围。

AUCint指定时间区间
AUCint(a, b) = ∫ₐᵇ C(t) dt，b > a

例如计算 0–4 h、4–12 h 的部分 AUC。区间边界不落在实际采样点时，需要按指定插值或外推规则得到边界浓度。

2.3 末端消除、半衰期与外推 AUC

Lambda_z末端消除速率常数
ln(C) = α − Lambda_z × t
Lambda_z = − slope[ ln(C) ~ t ]

选择合理的末端对数线性阶段数据点，进行简单线性回归。斜率应为负，Lambda_z 为其相反数，单位一般为 1/h。通常至少使用 3 个有效浓度点。

HL_Lambda_z末端消除半衰期
t½ = ln(2) / Lambda_z ≈ 0.693147 / Lambda_z

依赖 Lambda_z 的有效估计。如果时间单位是 h，则半衰期单位也是 h。

Rsq_adj调整后的决定系数
R²adj = 1 − (1 − R²) × (n − 1) / (n − 2)

这里 n 为回归使用的末端数据点数，公式适用于一个自变量（时间）且包含截距的简单线性回归，要求 n ≥ 3。用于评估末端拟合，不等同于普通 R²。

AUCinf0 至无穷时间的 AUC
AUCinf = AUClst + Clast / Lambda_z
%AUCextrap = 100 × (AUCinf − AUClst) / AUCinf

Clast 可依据配置采用最后实测浓度（observed）或在 tlast 的回归预测浓度（predicted），两者结果可能不同。缺乏可信的 Lambda_z 时，不宜强行外推。

2.4 滞留时间、清除率与波动指数

MRTinf平均滞留时间
AUMCinf = ∫₀∞ t × C(t) dt
AUMCinf = AUMClast + tlast × Clast / Lambda_z + Clast / Lambda_z²
MRTinf = AUMCinf / AUCinf（非静脉输注）

AUMC 为浓度乘时间的一阶矩曲线下面积。单次恒速静脉输注的 MRT 通常还需扣除 输注时长 / 2；血管外给药所得 MRT 也包含平均输入/吸收时间，不能简单解释为纯体内系统滞留时间。

CL清除率，静脉给药
CL = Dose / AUCinf（单次 IV 给药）

对于线性 PK 条件下的稳态静脉给药，也常使用 CLss = Dose / AUCtau,ss。确保 Dose 与 AUC 的质量和时间单位一致。

CL/F表观清除率，血管外给药
CL/F = Dose / AUCinf（单次给药）

F 为绝对生物利用度；血管外给药而 F 未知时，通常只能得到 CL/F，不能直接写成 CL。稳态条件下可相应使用 Dose / AUCtau,ss 估计 CLss/F。

DF稳态波动指数
Cavg,ss = AUCtau,ss / τ
DF(%) = 100 × (Cmax,ss − Cmin,ss) / Cavg,ss

部分分析规定采用 Ctau,ss 代替 Cmin,ss：此时公式变为 100 × (Cmax,ss − Ctau,ss) / Cavg,ss。还应核对项目报告中 DF 是以百分数还是无量纲小数呈现。

3. PK 数据处理与 λz 参数的 QC 判定

处理顺序是：原始浓度 → NCA 计算用浓度 → 个体 PK 参数 → 参数级统计纳入。缺失、NC 和“计算成功但不参与统计”是三种不同情况。以下阈值为匿名 SAP 教学示例，并非 CDISC 统一规定。

3.1 缺失浓度、NC 与统计排除

情况个体 Listing汇总与模型
PK 浓度未采集或缺失保留原始缺失状态不插补，不作为有效浓度计算或汇总
参数无法从有效浓度计算（NC）可按 Shell 显示 NC（Not Calculable）作为缺失，不参与描述统计、方差分析或食物影响模型
参数已计算，但 QC 不合格保留计算值、质量指标及排除原因用参数级分析标志排除，不应简单清空原始数值

NC 是字符型展示概念，数值型 ADPP AVAL 不应写入字符 NC。仅因统计不纳入而清空 AVAL，会损害 QC 的可追溯性。

3.2 BQL（低于定量下限）按位置处理

浓度用于 NCA 时，常见示例规则如下；计算用 0 不等于原始检测值为 0。记录与 Listing 应保留原始 BQL 信息。

BQL 出现位置NCA 使用核查点
Tmax 前的 BQL0不把 0 用于 ln(C) 末端回归
Tmax 后的 BQL缺失包括末端连续 BQL
两个可定量浓度之间的单个 BQL缺失不能擅自置 0 使区间 AUC 偏低
末端连续 BQL 后再次出现的可定量值按该示例视为缺失检查异常回升及 SAP 约定
个体浓度–时间图峰前 BQL 为 0，峰后 BQL 缺失绘图规则与原始 Listing 分开管理

例如 0h:BQL → 1h:2 → 2h:BQL → 4h:6 → 8h:BQL，计算输入可变成 0 → 2 → 缺失 → 6 → 缺失。跨越缺失时间点的积分方式仍取决于 NCA 配置，不可自行补点。

3.3 λz 为什么至少需要 3 个非零浓度？

从末端消除相选择至少 3 个正值、可定量且适合对数线性拟合的浓度点，做 ln(C) 对时间的线性回归。要求不只是 3 个非零数，还必须位于合理的末端消除阶段，斜率应为负。

ln(C) = α − λz × t；λz = −slope；t½ = ln(2)/λz

两个点虽然能确定直线，却不足以可靠评价消除相拟合质量。拟合点数、时间跨度、观察曲线及调整后的决定系数 Rsq_adj 都要结合判断；普通 R² 不能替代 Rsq_adj。

Rsq_adj = 1 − (1 − R²) × (n − 1)/(n − 2)（单自变量含截距，n≥3）

示例判定：Rsq_adj < 0.80，λz 与基于 λz 计算的其他参数不参与描述统计、方差分析和食物影响分析；刚好 0.80 不触发“低于”这一条件。

3.4 基于 λz 计算的参数有哪些？

两条主要路径：① λz 直接产生 t½、外推 AUCinf 和 AUMCinf；② AUCinf、AUMCinf 再参与 MRTinf、CL、CL/F、Vz、Vss 等计算。

λz → t½；λz → AUCinf → CL / CL/F → Vz / Vz/F
λz → AUMCinf；AUMCinf + AUCinf → MRTinf → Vss（IV）
参数典型计算依赖（单次给药 NCA）Rsq_adj < 0.8%AUCex > 20%
λz、t½末端回归；t½=0.693/λz排除不因此单独排除
AUCinf（Obs/Pred）AUClast + Clast/λz排除排除
AUMCinf末端外推含 Clast/λz²排除不一定*
MRTinfAUMCinf/AUCinf（输注需校正）排除排除
CL、CL/F（单次）Dose/AUCinf排除排除
Vz、Vz/FCL/λz 或 (CL/F)/λz排除排除
Vss（IV）CL × MRT，依赖 AUCinf排除排除
AUCinf/Dose及其他 AUCinf 衍生比值直接使用 AUCinf排除排除
Cmax、Tmax、AUClast观测峰值、达峰时点和实测范围积分通常保留通常保留
AUCtau、AUCint、Ctrough、DF规定区间/稳态数据，无需末端外推时通常保留**通常保留**

* AUMCinf 依赖 λz，但不由 AUCinf 数值直接计算。若规则只限制“基于 AUCinf 的参数”，仅 %AUCex 超标并不自动推出 AUMCinf 必须排除；应核对 SAP 是否另作规定。** AUCtau 或区间 AUC 如实际使用末端外推，其依赖关系需要重新判定。稳态 CLss/F=Dose/AUCtau,ss 通常不属于单次 AUCinf 分支。

3.5 Rsq_adj 与 %AUCex 控制的是不同集合

%AUCex = 100 × (AUCinf − AUClast) / AUCinf

当 %AUCex > 20%，按此示例规则只排除 AUCinf 及由 AUCinf 计算的其他参数；当 Rsq_adj < 0.80，排除范围更广，覆盖 λz 及整条 λz 衍生参数链。如果两项同时不满足，采用两个排除集合的并集。

虚构例子：Rsq_adj = 0.92、%AUCex = 28%，则 t½ 通常仍可分析，AUCinf、CL/F 不纳入；若 Rsq_adj = 0.75、%AUCex = 12%，即使外推比例低，t½、AUCinf、CL/F 也应依照 λz 质量规则排除。等于 20% 不触发“高于 20%”条件。

3.6 ADPP / TFL 程序如何实现？

按 受试者 × 分析物 × 给药周期/分析时段 汇总拟合点数、Rsq_adj、%AUCex 等 QC 信息，再按 PARAMCD 标记是否依赖 λz 或 AUCinf。对每条参数赋分析标志（如 ANL01FL）及排除原因，不要整个人删除或抹掉已计算的 AVAL。

/* 教学伪代码：依赖分类按本项目 PARAMCD Spec 配置
   未在 SAS 实际执行，不能直接复制替代生产逻辑 */
bad_lz = missing(lambda_z) or n_lz < 3
         or missing(rsq_adj) or rsq_adj < 0.80;
bad_aucinf = bad_lz or
             (not missing(auc_ex_pct) and auc_ex_pct > 20);

if missing(aval) then anl01fl = '';
else if lz_dep='Y' and bad_lz then anl01fl = '';
else if aucinf_dep='Y' and bad_aucinf then anl01fl = '';
else anl01fl = 'Y';

缺少拟合诊断数据时，应标记待复核/NC 原因，不应默认为合格。lz_dep、aucinf_dep 为教学用元数据，不是 CDISC 标准字段。QC 要追溯同一受试者、分析物、周期的终末回归，验证列表保留、统计排除以及模型筛选是否一致。

3.7 PK 参数描述统计及对数变换

CV% = 100 × SD / Mean
GeoMean = exp[Mean(ln x)]；GeoSD = exp[SD(ln x)]
GeoCV% = 100 × √(exp{SD(ln x)²} − 1)

原尺度 Mean、SD、CV% 与对数尺度 GeoMean、GeoSD、GeoCV% 不可混用。几何统计仅对正数适用；GeoCV% 不是 SD / GeoMean。Tmax 常以 n、Median、Min、Max 为主，具体保留统计量见 Shell/SAP。另见 PK 浓度统计量专题。

4. 手算核对示例

假设相邻样本分别为 t₀ = 0 h, C₀ = 2 ng/mL 和 t₁ = 2 h, C₁ = 6 ng/mL，采用线性梯形法：

AUC₀–₂ = (2 + 6) / 2 × (2 − 0) = 8 ng·h/mL

另假设 AUClst = 40 ng·h/mL、Clast = 1 ng/mL、Lambda_z = 0.2 h⁻¹，按 observed 外推方式：

AUCinf = 40 + 1 / 0.2 = 45 ng·h/mL
%AUCextrap = (45 − 40) / 45 × 100 ≈ 11.11%
t½ = 0.693147 / 0.2 ≈ 3.47 h

这些数值仅用于演示公式，不构成真实研究数据或参数合理性判定。

5. 使用说明与来源

PK 参数术语和计算公式参考公开 CDISC 术语及 Certara Phoenix NCA 文档。第 3 节是经过去标识化整理的通用 SAP 规则教学示例；其中的阈值和 BQL 规则不能视为 CDISC、监管机构对所有项目的统一要求。

适用范围以血浆/血清浓度的常见 NCA 为主。BQL 处理、采样时点、给药途径、首次给药与稳态、梯形法、末端拟合范围、obs/pred 外推方式及参数命名必须与具体 SAP / PK 分析计划一致。本文所列名称沿用个人笔记，不应直接视为 CDISC 规定的唯一 PARAMCD。
