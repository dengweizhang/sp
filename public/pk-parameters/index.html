2. 参数计算方法

以下采用血浆/血清浓度的非房室分析（NCA）框架。以给药时刻为 t = 0，tᵢ 为实际采样时间，Cᵢ 为对应可用于分析的浓度；Dose 为给药剂量，τ 为给药间隔。公式主要用于理解和独立 QC，不代替项目配置。

2.1 直接从观测浓度读取

Cmax峰浓度
Cmax = max(Cᵢ)

分析时间范围内观测到的最大浓度，不需要拟合；若存在并列最大值，Tmax 的取值规则应在分析计划中明确。

Tmax达峰时间
Tmax = time at observed Cmax

对应 Cmax 的采样时间。Phoenix NCA 在并列峰值时选择第一次出现的时间；不是通过曲线插值得到的理论达峰时刻。

Ctrough谷浓度
Ctrough ≈ 给药间隔末端或下一次给药前的浓度

通常取规定的给药前样本或 τ 时点浓度；实际采用观测值还是估算值依 SAP / PK 分析计划。Ctrough 不必然等于给药间隔内最低的 Cmin。

2.2 先计算曲线下面积（AUC）

相邻两个时间点的面积先逐段计算，再在指定区间求和。常用方法如下：

线性梯形法Linear trapezoidal
AUCᵢ = (Cᵢ + Cᵢ₊₁) / 2 × (tᵢ₊₁ − tᵢ)

适用于线性计算规则下的相邻采样区间。

对数梯形法Log trapezoidal
AUCᵢ = (Cᵢ − Cᵢ₊₁) / ln(Cᵢ / Cᵢ₊₁) × (tᵢ₊₁ − tᵢ)

通常用于浓度下降且两端浓度均为正、不相等的区间。常见配置为 Linear-up / Log-down，但不能默认所有项目相同；不满足对数法计算条件时按软件规则使用线性法。

AUClst0 至最后可测定浓度时点
AUClst = Σ AUCᵢ，积分范围为 0 → tlast

tlast 为最后可测定浓度对应时间。AUClst 不等于积分到最后一次采样时间的 AUCall，尤其当末次样本为 BQL 时。

AUCtau一个给药间隔
AUCtau = ∫₀^τ C(t) dt

积分区间为本次给药至 τ；通常用于多次给药/稳态评估。若 τ 处没有观测浓度，可能需要插值或外推，能否计算取决于分析规则和数据覆盖范围。

AUCint指定时间区间
AUCint(a, b) = ∫ₐᵇ C(t) dt，b > a

例如计算 0–4 h、4–12 h 的部分 AUC。区间边界不落在实际采样点时，需要按指定插值或外推规则得到边界浓度。

2.3 末端消除、半衰期与外推 AUC

Lambda_z末端消除速率常数
ln(C) = α − Lambda_z × t
Lambda_z = − slope[ ln(C) ~ t ]

选择合理的末端对数线性阶段数据点，进行简单线性回归。斜率应为负，Lambda_z 为其相反数，单位一般为 1/h。通常至少使用 3 个有效浓度点。

HL_Lambda_z末端消除半衰期
t½ = ln(2) / Lambda_z ≈ 0.693147 / Lambda_z

依赖 Lambda_z 的有效估计。如果时间单位是 h，则半衰期单位也是 h。

Rsq_adj调整后的决定系数
R²adj = 1 − (1 − R²) × (n − 1) / (n − 2)

这里 n 为回归使用的末端数据点数，公式适用于一个自变量（时间）且包含截距的简单线性回归，要求 n ≥ 3。用于评估末端拟合，不等同于普通 R²。

AUCinf0 至无穷时间的 AUC
AUCinf = AUClst + Clast / Lambda_z
%AUCextrap = 100 × (AUCinf − AUClst) / AUCinf

Clast 可依据配置采用最后实测浓度（observed）或在 tlast 的回归预测浓度（predicted），两者结果可能不同。缺乏可信的 Lambda_z 时，不宜强行外推。

2.4 滞留时间、清除率与波动指数

MRTinf平均滞留时间
AUMCinf = ∫₀∞ t × C(t) dt
AUMCinf = AUMClast + tlast × Clast / Lambda_z + Clast / Lambda_z²
MRTinf = AUMCinf / AUCinf（非静脉输注）

AUMC 为浓度乘时间的一阶矩曲线下面积。单次恒速静脉输注的 MRT 通常还需扣除 输注时长 / 2；血管外给药所得 MRT 也包含平均输入/吸收时间，不能简单解释为纯体内系统滞留时间。

CL清除率，静脉给药
CL = Dose / AUCinf（单次 IV 给药）

对于线性 PK 条件下的稳态静脉给药，也常使用 CLss = Dose / AUCtau,ss。确保 Dose 与 AUC 的质量和时间单位一致。

CL/F表观清除率，血管外给药
CL/F = Dose / AUCinf（单次给药）

F 为绝对生物利用度；血管外给药而 F 未知时，通常只能得到 CL/F，不能直接写成 CL。稳态条件下可相应使用 Dose / AUCtau,ss 估计 CLss/F。

DF稳态波动指数
Cavg,ss = AUCtau,ss / τ
DF(%) = 100 × (Cmax,ss − Cmin,ss) / Cavg,ss

部分分析规定采用 Ctau,ss 代替 Cmin,ss：此时公式变为 100 × (Cmax,ss − Ctau,ss) / Cavg,ss。还应核对项目报告中 DF 是以百分数还是无量纲小数呈现。

3. Lambda_z 评估注意事项

Lambda_z 通常由末端对数线性消除阶段的浓度数据拟合得到。原始笔记记录的实践要点如下：

  • 将浓度取对数后与时间进行线性回归，估计末端斜率。
  • 仅使用能代表末端对数线性消除阶段的数据点，通常至少需要 3 个有效点。
  • 可先尝试自动选择末端拟合范围；如不合适，再结合曲线检查并指定合理的时间范围。

原笔记中的判断参考（并非通用标准）

拟合相关性：记录了 R² ≥ 0.80 的参考阈值；AUCinf 外推比例：记录了 < 20% 的参考阈值，以及 > 40% 时需特别审慎的情形。例外应具有记录和合理解释。

上述阈值可能因项目要求、软件、分析计划不同而变化；R² 也不等同于 Rsq_adj。

4. 手算核对示例

假设相邻样本分别为 t₀ = 0 h, C₀ = 2 ng/mL 和 t₁ = 2 h, C₁ = 6 ng/mL，采用线性梯形法：

AUC₀–₂ = (2 + 6) / 2 × (2 − 0) = 8 ng·h/mL

另假设 AUClst = 40 ng·h/mL、Clast = 1 ng/mL、Lambda_z = 0.2 h⁻¹，按 observed 外推方式：

AUCinf = 40 + 1 / 0.2 = 45 ng·h/mL
%AUCextrap = (45 − 40) / 45 × 100 ≈ 11.11%
t½ = 0.693147 / 0.2 ≈ 3.47 h

这些数值仅用于演示公式，不构成真实研究数据或参数合理性判定。
