临床药理学基础：从 ADME 到 PK/PD

学习药物为何需要这些给药、采样和安全性评价，再理解 PK/PD 与 ADPC、ADPP、ADLB、ADEG 和 TFL 的联系。

为什么 SP 需要懂一点药理学？

药理学决定“为什么这样给药、为什么在这些时点采血、为什么既有 PK 又有 PD、为什么还要看安全性”；统计编程则负责把这些科学问题准确映射为可追溯的数据和输出。

这篇从临床试验真正高频的临床药理（Clinical Pharmacology）入手，而不是完整药理学教科书。常用 PK 参数的详细计算公式与 PARAMCD 已有专文，这里重点理解药物过程和临床意义；与之配套可读 临床试验统计学基础。

1. 一张图理解：剂量 → 暴露 → 效应

DOSE给药剂量mg、mg/kg、给药频率、途径
→
PK / EXPOSURE体内暴露Cmax、AUC、Ctrough、浓度–时间曲线
→
PD / RESPONSE药理效应生物标志物、疗效、毒性与耐受性

核心逻辑：给了相同剂量的人，体内暴露不一定相同；体内暴露相似的人，反应也可能不相同。器官功能、年龄、体重、遗传、合并用药和疾病状态都可能影响这个过程，因此需要临床药理研究。

PK（Pharmacokinetics）研究人体如何影响药物的浓度与时间过程；PD（Pharmacodynamics）研究药物对人体产生什么生物学作用。Exposure–Response 将药物暴露与有效性/安全性结果联系起来，帮助选择给药剂量和方案。

2. ADME：药物进入人体后发生什么？

阶段是什么对临床试验的影响
A — Absorption
吸收		药物从给药部位进入系统循环口服与静脉给药不同；食物影响研究、Tmax、Cmax、F
D — Distribution
分布		药物在血液、组织及不同空间之间分配表观分布容积、蛋白结合、组织分布与效应部位
M — Metabolism
代谢		药物被生物转化；可形成活性或非活性代谢物肝脏代谢、CYP、亲药物与代谢物的分析物区分
E — Excretion
排泄		药物及其代谢物通过肾脏、胆汁等途径离开人体肾功能损害研究、尿药浓度、排泄率、清除率

ADME 的结果可以解释为什么需要肝/肾功能相关协变量、为什么排除某些合并用药、为什么采血时间覆盖多个半衰期。药物从体内“清除”（Elimination）通常涉及代谢和排泄，不能把代谢率直接当成尿排泄率。

从 SP 数据理解 ADME

一次质量平衡研究可能涉及血浆、尿液、粪便以及原形药与代谢物。需要先区分样本基质、分析物、采集区间和单位，再计算适当参数。记录中仅有“药物浓度”四个字还不够。

3. PK 参数：先理解它代表什么，再看公式

参数直观解释常见 SP 注意点
Cmax / Tmax观测峰浓度 / 达到观测峰的时间采样时间、并列峰值、BLQ、单位
AUC浓度–时间曲线下面积，反映系统暴露积分时间区间、梯形法、观测/外推
t½ / Lambda_z末端浓度下降速度及相应半衰期末端拟合点、拟合可靠性、观察期
CL / CL/F药物从系统循环被清除的能力；血管外给药常报告表观清除率给药途径、生物利用度、剂量与 AUC 单位
V / V/F描述浓度与体内药量关系的表观分布容积参数依模型与给药途径而异，不等于真实器官体积
AUCtau / Ctrough给药间隔内暴露 / 间隔末端谷浓度MAD、给药前样本、稳态时间窗
Rac / 蓄积比重复给药后相对于初次给药的暴露或浓度增加程度参数定义须明确使用 AUC、Cmax 或 Ctrough

常见表达式：单次静脉给药的 CL = Dose / AUCinf；血管外给药通常得到 CL/F。对于理想的一室线性消除模型，t½ ≈ 0.693 × V / CL，但不能对复杂多室或非线性药物直接当作普遍恒等式。

进入具体公式、单位换算、梯形法或 PARAMCD 映射，请阅读 《常用 PK 参数》↗。

4. PD 与作用机制：药物如何产生效果？

药物可以作用于受体、酶、离子通道或其他生物靶点。作用机制（Mechanism of Action，MoA）解释为什么产生某种药理效应；PD 指标度量药物的生物学效应；而临床疗效终点则衡量对患者有意义的临床结果，三者可能相关，却不是同一个概念。

层级典型例子SP 关注
靶点 / 机制受体激动、拮抗，或酶抑制等通常由 Protocol/IB 描述，不直接由 SP 推断
PD 生物标志物某类激素、细胞亚群、靶点占有率、生物学信号参数、单位、访视、基线、百分比变化
临床疗效终点HbA1c、体重变化、肿瘤缓解、症状改善主/次终点定义、分析集、时间窗、模型
安全性响应实验室异常、心率变化、QTc、特定 AE暴露对应时间、基线、异常标志、事件时点

常见浓度–效应模型之一是 E(C) = E0 + Emax × C / (EC50 + C)，但这是简化的直接效应 Emax 模型，不适用于所有药物；如果存在效应延迟、耐受或复杂反馈，通常需要其他模型。

记住：药物浓度提高并不意味着临床疗效一定线性增加，也不意味着毒性一定以相同方式增加。

5. SAD、MAD、稳态与蓄积

SAD 主要研究单次给药后的安全性与暴露；MAD 则更关心反复给药后的暴露变化、潜在蓄积、给药间隔和稳态情况。

概念理解方式SP 需要核查
Steady State（稳态）在重复规律给药下，药物输入和清除达到周期性平衡，浓度曲线周期间基本重复给药日、实际给药时间、周期和稳态判定依据
τ（给药间隔）例如 q24h 对应 24 小时间隔实际间隔、漏服/推迟给药、采样窗口
Accumulation（蓄积）多次给药后的暴露高于相同给药方案初次给药暴露蓄积比用 AUCtau 还是 Cmax、使用哪两个评价日
Dose Proportionality剂量变化时暴露是否近似成比例变化剂量实际值、AUC/Cmax、可能使用 Power Model

对简单线性一阶动力学系统，经过约 4–5 个相关半衰期可能接近稳态，这是帮助理解的经验估计，不是所有药物都适用的硬性判定标准；长半衰期、多室、时间依赖性清除和生物大分子都可能使情况更复杂。

固定给药间隔内的 AUCtau 以及稳态下的 Cmax,ss / Cmin,ss / Cavg,ss 可用于反映暴露和波动，但不能把 Ctrough 自动等同于整个周期最低的 Cmin。

6. 为什么会做食物影响、DDI、肝肾功能和质量平衡研究？

临床药理研究研究问题SP / PK 对应
Food Effect（食物影响）进食是否改变药物吸收程度或速度？空腹/餐后、序列、周期、Cmax/AUC
DDI（药物相互作用）合并用药是否改变暴露或药理作用？合并用药/给药时点、分析物、暴露比与 CI
肝功能损害代谢、蛋白结合等变化是否影响暴露？肝功能分组与参数、暴露量及用药建议
肾功能损害肾排泄或相关生理过程变化是否影响暴露？肾功能分组、eGFR、暴露变化
Mass Balance / ADME给药后原形药和代谢产物去了哪里？血、尿、粪、放射性物质平衡、回收率
QT / QTc药物暴露是否影响心脏复极？ECG 时间、QTcF、ΔQTc、浓度–QTc 关系

DDI 常涉及药物作为底物（Substrate）、抑制剂（Inhibitor）或诱导剂（Inducer），特别是 CYP 酶与转运体（例如 P-gp）。抑制/诱导可能改变药物清除或吸收，但影响方向和大小必须结合具体机制，不能凭药物类别机械推断。

在临床试验中，QTc 是对心电图 QT 间期进行心率校正后的指标；例如 QTcF = QT / RR^(1/3)（QT、RR 单位需一致）。QTc 不是药物浓度，QTc 延长也不能等同于已经发生了恶性心律失常。

7. 生物利用度（BA）与生物等效性（BE）

BA（Bioavailability）关注给药后活性药物成分进入系统循环的程度和速度；F（绝对生物利用度）通常以血管外与静脉给药的剂量校正 AUC 比值估计，在适宜的线性与可比条件下：

F = (AUC_extravascular / Dose_extravascular) / (AUC_IV / Dose_IV)

BE（Bioequivalence）比较试验制剂与参比制剂的生物利用度是否在规定标准内接近。常规平均 BE 的 PK 方法可能对 AUC 和 Cmax 进行对数变换，比较 Test/Reference 几何均值比（GMR）及其 90% CI。

如何理解 80%–125%？

在适用的常规 BE 监管情境中，通常要求相应 PK 参数的90% CI 整体落在预设的 80.00%–125.00% 区间。这不是说 80%–125% 的受试者等效，也不是“药物纯度在 80%–125% 之间”。高变异药物、窄治疗指数药物及特定产品另有规则，应使用当期适用指南。

交叉 BE 研究还要关注 Sequence、Period、Treatment、受试者嵌套/重复测量结构。SP 需要根据 SAP 构建可用的 PK 参数记录，而不能只简单求算术均值比。

8. NCA、PopPK、暴露–反应：三者是什么关系？

方法解决什么问题常见数据要求
NCA不预设明确房室结构，通过浓度–时间数据估计单个受试者的 PK 参数精确给药和采样时间、浓度、分析物、BLQ 规则
PopPK用群体模型估计典型 PK 参数、个体差异及协变量影响；可处理较稀疏的采样设计长期观测数据、剂量事件、协变量、个体 ID、给药途径
Exposure–Response将暴露与疗效或安全性结果联系起来，以支持剂量选择和风险评估暴露指标、PD/疗效终点、安全性及相关协变量

三者不是同义词，也不互相排斥。一项研究可能先做 NCA，再结合多研究数据做 PopPK 或暴露–反应分析。群体药代模型不意味着一定由 SAS SP 编写，但 SP 可能承担数据准备、集成、Listing 与 QC。

9. 免疫原性、ADA 与 NAb

某些治疗性蛋白或生物制品可能激发针对药物的免疫反应。ADA（Anti-Drug Antibody）指抗药抗体；NAb（Neutralizing Antibody）是具有中和功能的抗体，属于 ADA 反应中的功能性类别，并非每个 ADA 阳性样本都一定有 NAb。

免疫原性可能影响药物暴露、安全性和疗效，但不能从一次 ADA 阳性推断一定发生临床不良反应。研究中可能涉及基线状态、治疗后阳转、滴度和持久性等定义。

SP 关注：免疫原性分析集、检测时间点、阳性/阴性规则、基线反应、不同试剂盒的记录层级，以及与 PK 浓度或临床事件的对应分析。各标志和衍生算法必须按方案及分析计划实现。

11. 面试与自测：能解释“为什么这样做”吗？

Q1. PK 和 PD 最简单的区别？

PK 研究体内药物浓度随时间变化及 ADME；PD 研究药物引起的生物效应。药物剂量、暴露、效应并非总有线性关系。

Q2. 为什么 SAD/MAD 会安排很多 PK 采血时点？

需要覆盖吸收、峰值、分布及消除阶段，以尽量可靠地估计 Cmax、Tmax、AUC、半衰期等；MAD 还需观察给药间隔和稳态/蓄积。

Q3. 口服药为什么常报告 CL/F 而不是 CL？

绝对生物利用度 F 未知时，血管外给药利用剂量和 AUC 能估计的是表观清除率 CL/F，不能直接视为真实系统清除率 CL。

Q4. QTc 延长与 TEAE 是一个意思吗？

不是。QTc 是经过校正的 ECG 数值指标；TEAE 是根据治疗期和不良事件定义判断的治疗期间出现事件。两者可能有关，但不等价。

Q5. 药物 1 个半衰期后一定清除完吗？

不是。在线性一阶消除的简化情况下，经过一个半衰期浓度约减少一半，不是归零；复杂动力学更不能套用固定清除时间。

Q6. ADA 阳性是否一定有中和抗体或疗效下降？

不一定。NAb 是具有功能性中和作用的抗体，应以专门检测及临床关联分析判断，不能从 ADA 阳性直接推出疗效下降。

Q7. BE 的 80%–125% 是什么标准？

在适用的常规平均生物等效性比较情境中，指规定 PK 参数的 Test/Reference GMR 的 90% CI 完全处于预设区间内，而非受试者达标比例。

一段更完整的面试表达：“我参与过早期临床 PK 项目，理解 SAD/MAD 主要通过给药后浓度–时间资料评价安全性、耐受性和体内暴露，并关注重复给药的蓄积情况。在编程中，我尤其核对实际给药与采样时间、分析物、浓度单位、不同剂量/周期的参数及安全性时间窗口。”具体表述须与你真实参与的工作一致。
