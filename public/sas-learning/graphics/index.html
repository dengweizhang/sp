SAS 绘图：SGPLOT / SGPANEL 到临床 TFL

单组/多组折线、均值与误差线、分面图、轴和图例；重点排查首尾错误连线、采样时间排序及图形 QC。

01 基础02 实战03 进阶 / QC
LEVEL 1 · 基础

SCATTER 与 SERIES

散点适合个体观测，SERIES 按 X 连接同一个组的多个点。先明确 X/Y 是实际日期、数值时间还是展示标签。

proc sgplot data=sashelp.class;
  scatter x=height y=weight / group=sex;
  xaxis label="Height";
  yaxis label="Weight";
run;

检查重点：变量类型、单位和坐标轴顺序要与图注一致；X 数值与显示 FORMAT 分开检查。

LEVEL 2 · TFL 实战

组均值折线 + 误差棒

把每组每访视的均值和 CI/SD 上下界整理成每组每时点一行。图表只负责展示，不应临时计算不受控的分析口径。

data plot_demo;
  do trt=1 to 2;
    do visit=1 to 4;
      mean=10+2*trt+visit;
      lower=mean-1; upper=mean+1;
      output;
    end;
  end;
run;
proc sgplot data=plot_demo;
  series x=visit y=mean / group=trt markers;
  scatter x=visit y=mean /
    group=trt yerrorlower=lower yerrorupper=upper;
  xaxis integer;
  yaxis label="Example Mean";
run;

检查重点：示意误差界不是实算的 SD/CI；正式图应从 QC 过的汇总数据集中读取误差范围。

LEVEL 3 · 进阶 / QC

SGPANEL 与错误连线定位

多治疗组、多分析物时可分面。出现首尾相连或跨受试者连线，应先检查 GROUP、X 排序、重复时间点、缺失处理与分面键。

proc sgpanel data=plot_demo;
  panelby trt / columns=2;
  series x=visit y=mean / markers;
  colaxis integer;
  rowaxis label="Example Mean";
run;

检查重点：同组同时间多条记录、未使用正确 GROUP、X 是字符型时间标签等都可能造成误导；先整理绘图数据再修样式。

学习边界：代码使用 SASHELP 或自造示例，仅为官方语法参考与学习示范，未在本次对话的 SAS 环境执行；进入正式 TFL 前须按 SAP、Spec 和独立 QC 核对。
