SAS 绘图：SGPLOT / SGPANEL 到临床 TFL

图形很直观，也容易让错误更直观。我们之前碰到过浓度曲线首尾相连、时间点顺序不符合预期的现象：这往往不是画图指令少写了一个美化参数，而是数据结构仍没准备好。

点与线的差别图里的不确定性先修数据再修图

为什么同样的点，SCATTER 正常，SERIES 却可能画错？

散点只标出每条观测，折线却必须决定哪些点属于同一条轨迹、按什么 X 顺序连接。画个体浓度曲线时，受试者、分析物和阶段通常都可能是分组条件；如果这些条件丢了，线会跨过本不该连接的记录。

proc sgplot data=sashelp.class;
  scatter x=height y=weight / group=sex;
  xaxis label="Height";
  yaxis label="Weight";
run;

回到数据核对：变量类型、单位和坐标轴顺序要与图注一致；X 数值与显示 FORMAT 分开检查。

一条均值曲线，为什么还需要误差线？

均值只告诉我们中心在哪，不能告诉我们这个估计有多分散或多不确定。SD、SE 与 CI 的含义不同。建议先在数据层按正确分母生成上下界，再让 SGPLOT 展示；不要在绘图阶段临时定义统计规则。

data plot_demo;
  do trt=1 to 2;
    do visit=1 to 4;
      mean=10+2*trt+visit;
      lower=mean-1; upper=mean+1;
      output;
    end;
  end;
run;
proc sgplot data=plot_demo;
  series x=visit y=mean / group=trt markers;
  scatter x=visit y=mean /
    group=trt yerrorlower=lower yerrorupper=upper;
  xaxis integer;
  yaxis label="Example Mean";
run;

回到数据核对：示意误差界不是实算的 SD/CI；正式图应从 QC 过的汇总数据集中读取误差范围。

出现‘首尾相连’时，该先检查图形颜色还是数据？

先看同组 X 是否按数值时间排序，再查重复时点、缺失、组标识以及是否把多个受试者放进同一条 SERIES。只有确认数据连接关系正确，才值得调整图例、坐标轴与 SGPANEL 的分面布局。

proc sgpanel data=plot_demo;
  panelby trt / columns=2;
  series x=visit y=mean / markers;
  colaxis integer;
  rowaxis label="Example Mean";
run;

回到数据核对：同组同时间多条记录、未使用正确 GROUP、X 是字符型时间标签等都可能造成误导；先整理绘图数据再修样式。
