PROC FREQ：从频数到分类统计

单维频数、列联表、行/列百分比、OUT=、OUTPCT、ODS、CHISQ 和 EXACT，连接到 TFL 的 n (%)。

01 基础02 实战03 进阶 / QC
LEVEL 1 · 基础

TABLES / MISSING / 百分比口径

TABLES 一维看频数，二维看交叉分类。二维表默认展示 cell / row / column 等不同百分比，必须明确分母。

proc freq data=sashelp.class;
  tables sex;
  tables sex*age / missing;
run;

检查重点：同一受试者多条记录时 FREQ 统计行数，而非自动去重的受试者数。

LEVEL 2 · TFL 实战

OUT= / OUTPCT / SPARSE

先通过 FREQ 得到分类计数，再按 SAP 的分析人群 N 计算 TFL 百分比；SPARSE 可以让二维表输出零计数单元格的组合（基于实际分类水平）。

proc freq data=sashelp.class noprint;
  tables sex*age / out=freq_cells outpct sparse;
run;

proc print data=freq_cells noobs;
  var sex age count percent pct_row pct_col;
run;

检查重点：OUTPCT 输出中的百分比字段（如 PCT_ROW、PCT_COL）口径不同；未出现的完整类别通常仍需用显式 shell 补齐。

LEVEL 3 · 进阶 / QC

ODS 检验输出：CHISQ / EXACT

ODS OUTPUT 可以捕获统计过程产生的对象。卡方检验和 Fisher 精确检验是否合适取决于设计与期望频数。

ods output ChiSq=chisq_result;
proc freq data=sashelp.class;
  tables sex*age / chisq;
run;
ods output close;

检查重点：这个表的 age 有多个水平，不能把输出的所有 P 值都当作唯一正式 P 值；分析方法必须以 SAP 为准，若需 Fisher 可进一步查 EXACT 语句。

学习边界：代码使用 SASHELP 或自造示例，仅为官方语法参考与学习示范，未在本次对话的 SAS 环境执行；进入正式 TFL 前须按 SAP、Spec 和独立 QC 核对。
