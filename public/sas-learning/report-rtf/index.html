PROC REPORT：跨列分组与 RTF 样式

把问题拆开：COLUMN 决定表头结构；DEFINE/STYLE 决定单元格布局；ODS TAGSETS.RTF 决定文件输出；RTF 原生控制字只负责特定格式微调。

01 · COLUMN 跨列标题，和 DEFINE / GROUP 的区别

你截图中的 Alcohol History 横跨 col3–col6，Smoking History 横跨 col7–col10，使用的是 PROC REPORT spanning column headers。只需要括号分组与组标题，基本语法不依赖 RTF raw 控制字。SAS 官方 COLUMN 说明

column page usubjid col1 col2
  ("Alcohol History" col3 col4 col5 col6)
  ("Smoking History" col7 col8 col9 col10);

/* DEFINE xx / GROUP 将多条数据按变量值汇总成行组；
   COLUMN ("标题" col3 col4) 是表头合并，不是行汇总。 */

多层表头可以嵌套括号，但最终单列仍应清楚对应变量的 DEFINE 定义、列宽与顺序。表头是否自动换行由 cellwidth、字体及 SPLIT 字符等共同决定。

02 · RTF 常用 STYLE 属性，分别控制什么？

位置 / 属性影响与常见目的
style(report)整个报表的区域宽度、边框等；如 outputwidth=100%
style(header)标题单元格统一字体、居中、底边框、底色等
style(column)数据列样式；比如左对齐与保留空白
DEFINE ... style(column)指定某一列的 CELLWIDTH、对齐和边框
JUST=left / center / right 对齐，单元格区域与段落实际呈现需在 Word 检查
CELLWIDTH=单列宽度；所有列宽总和要在页面可用宽度内
ASIS=ON允许保留数据中的原始空白（视 ODS 目的地而异）
BORDERBOTTOMWIDTH=标题/单元格下边框粗细，例如 1pt
BORDERBOTTOMCOLOR=标题/单元格下边框颜色
FONTSIZE= / FONTFAMILY=字体大小与字体族；建议项目统一到 STYLE 模板
SPLIT='|'用于把列标题中的 | 视作分行符；不要误用 ODS ESCAPECHAR 相同的字符

重要区别：全局 style(header) 影响多个层级标题，并不只控制 Alcohol / Smoking 一级组标题。如果需要一级组标题独有的线条或字体，优先考虑报表结构与模板；再评估 RTF 原生控制字。

03 · 最小完整示例：生成跨列组标题 RTF

使用 SASHELP.CLASS 构造演示数据，不包含任何实际临床试验记录。沿用你截图中的 ODS TAGSETS.RTF、PROC REPORT、DEFINE 结构和逐列设置宽度的习惯。代码为待在真实 SAS/Word 环境验证的教学示例。

/* 独立演示：生成不含项目数据的最终展示数据 */
data final;
  set sashelp.class(obs=4);
  length usubjid $8 col1-col10 $30;
  page=1;
  usubjid=put(_n_,z3.);
  col1=sex;
  col2=put(age,3.);
  col3=put(height,5.1);
  col4=put(weight,5.1);
  col5="Not Collected"; col6="";
  col7="No"; col8=""; col9=""; col10="";
run;

ods listing close;
ods escapechar='~';
ods tagsets.rtf file="report_demo.rtf"
  style=styles.rtf
  options(contents='no' toc='off'
          vspace='off' continue_tag='off');

proc report data=final nowd missing split='|'
    style(report)=[outputwidth=100%]
    style(header)=[just=center asis=on
                   borderbottomwidth=1pt
                   borderbottomcolor=black]
    style(column)=[just=left asis=on];

  column page usubjid col1 col2
      ("Alcohol History" col3 col4 col5 col6)
      ("Smoking History" col7 col8 col9 col10);

  define page    / order noprint;
  define usubjid / order "Subject ID"
      style(column)=[cellwidth=0.7in];
  define col1 / display "Sex"
      style(column)=[cellwidth=0.55in];
  define col2 / display "Age"
      style(column)=[cellwidth=0.5in];
  define col3 / display "Height"
      style(column)=[cellwidth=0.7in];
  define col4 / display "Weight"
      style(column)=[cellwidth=0.7in];
  define col5 / display "Status"
      style(column)=[cellwidth=0.8in];
  define col6 / display "Note"
      style(column)=[cellwidth=0.7in];
  define col7 / display "Smoking?"
      style(column)=[cellwidth=0.7in];
  define col8 / display "Start Date"
      style(column)=[cellwidth=0.75in];
  define col9 / display "Amount"
      style(column)=[cellwidth=0.6in];
  define col10 / display "Quit?"
      style(column)=[cellwidth=0.7in];
run;

ods tagsets.rtf close;
ods listing;

项目原程序使用 style=bnptemplate.rtf 及 pagepanels=1、contents/toc/vspace/continue_tag 等设置。这些选项服务于特定模板和 Tagset 版本，不是 COLUMN 跨列分组的必要条件；模板可用性应由项目环境确认。

04 · 截图中的 ~R 控制串究竟是什么？

截图里你写的 ~R'\qc\brdrb\brdrs\brdrw16' 不是 SAS 统计语法，而是借助 ODS ESCAPECHAR='~' 嵌入的 RTF 控制字。SAS 官方文档展示过目的地限定的 ~R/RTF 写法；项目里省略 /RTF 的旧写法，需按原 SAS/ODS 版本复现。

RTF 控制字含义
\qc当前段落居中（RTF paragraph centered）
\brdrb段落底边框
\brdrs单实线边框
\brdrw16边框宽度 16 twips，约 0.8 pt（1 pt = 20 twips）
/* 旧宏常见写法（需在相同 SAS/ODS 环境中验证） */
ods escapechar='~';
column page usubjid
  ("~R'\qc\brdrb\brdrs\brdrw16' Alcohol History"
    col3 col4 col5 col6)
  ("~R'\qc\brdrb\brdrs\brdrw16' Smoking History"
    col7 col8 col9 col10);

/* 文档示例推荐的目的地限定形式：~R/RTF */
column page usubjid
  ("~R/RTF'\qc\brdrb\brdrs\brdrw16' Alcohol History"
    col3 col4 col5 col6)
  ("~R/RTF'\qc\brdrb\brdrs\brdrw16' Smoking History"
    col7 col8 col9 col10);

选择顺序：先用 COLUMN 解决分组；再用 STYLE(HEADER)、DEFINE STYLE 调整对齐/边框；确实需要针对 RTF 目的地特殊段落效果时，才考虑 ~R/RTF。这些控制字在 PDF/HTML/EXCEL 不具有同等含义。

Raw RTF 可能被 ODS 转义、与 Word 段落/边框布局冲突或受模板影响。SAS 官方文档提供 R/RTF 示例，并非保证任何控制串在所有 ODS TAGSETS.RTF 版本的跨列标题里都按预期呈现；应打开生成的 RTF 做版面检查。

05 · RTF 排版问题该按什么顺序排查？

列宽/跨列错乱：先核对 CELLWIDTH 之和、纸张可打印宽度、标题过长和字体。多余空白/分页：检查隐藏排序列、BREAK/PAGE、COMPUTE BEFORE/AFTER、LINE、占位行及脚注高度。文件占用：打开 ODS TAGSETS.RTF 必须对应关闭 ODS TAGSETS.RTF；ODS RTF CLOSE 关闭的是另一目的地。

独立 QC：先对比简单样式（无 raw RTF 控制字）的输出，再逐项加 STYLE 与 raw；核对第一页/中间页/最后一页，检查跨列组标题是否真正覆盖正确列数、页眉/脚注是否重复、是否有空白页及列截断。
