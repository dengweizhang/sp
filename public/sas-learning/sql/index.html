PROC SQL：从查询到 TFL 数据汇总

从 SELECT、WHERE 到 GROUP BY、JOIN、DISTINCT、HAVING；重点解决受试者去重与分母口径问题。

01 基础02 实战03 进阶 / QC
LEVEL 1 · 基础

SELECT / WHERE / ORDER BY

先选列、筛行、排序；DISTINCT 去重复组合，不等同于按特定键保留首条记录。

proc sql;
  select name, sex, age
  from sashelp.class
  where age >= 13
  order by sex, age desc;
quit;

检查重点：先确认分析单位是一行记录还是一个受试者；SELECT DISTINCT 多列时，对整组列去重。

LEVEL 2 · TFL 实战

GROUP BY + COUNT(DISTINCT) + 单独分母

临床分类汇总中，事件记录数和发生事件的受试者数可能不同。分母从预定义人群独立计算，不能拿当前分类表的小计代替。

proc sql;
  create table total_n as
    select sex, count(distinct name) as big_n
    from sashelp.class group by sex;
  create table age_n as
    select sex, age, count(distinct name) as n
    from sashelp.class group by sex, age;
  create table summary as
    select a.*, b.big_n,
           100*a.n/b.big_n as pct format=6.1
    from age_n a left join total_n b
    on a.sex=b.sex;
quit;

检查重点：这个示例以 CLASS 的 name 当唯一键，仅演示统计机制；实际项目使用去重的 USUBJID，分母通常从 ADSL 对应人群计算。

LEVEL 3 · 进阶 / QC

HAVING 与 JOIN 行数膨胀

HAVING 在汇总后筛选分组。JOIN 之前必须检查右表连接键是否唯一，否则一个左表记录可能扩张成多行。

proc sql;
  /* 查看键是否重复 */
  select sex, count(*) as n
  from sashelp.class
  group by sex
  having calculated n > 1;

  /* 先把右表汇总成每个 sex 一行，再 join */
  create table key_unique as
  select sex, max(age) as maxage
  from sashelp.class group by sex;
  create table safe_join as
  select a.*, b.maxage
  from sashelp.class a
  left join key_unique b on a.sex=b.sex;
quit;

检查重点：JOIN 前后比较记录数，检查 JOIN 键唯一性与缺失匹配；需做存在性判断时优先考虑 EXISTS，避免无意义的 1:N 扩张。

学习边界：代码使用 SASHELP 或自造示例，仅为官方语法参考与学习示范，未在本次对话的 SAS 环境执行；进入正式 TFL 前须按 SAP、Spec 和独立 QC 核对。
