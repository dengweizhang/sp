统计汇总：MEANS / SUMMARY / UNIVARIATE

同样一批浓度或实验室数值，Mean、Median、SD、CV%、几何均值讲述的是不同的侧面。如果先不弄清统计对象，PROC MEANS 再快也只能产出一串看似整齐的数字。

一个 N 的疑问怎样按层级汇总偏态数据的另一种中心

Mean 只需一行代码，为什么最先要检查 N？

N 通常是非缺失观测的数量，而不是自动去重后的受试者数。在 ADLB 或 ADPC 中，一个人可能贡献多个访视或时点；如果把这些行混在一起计算，得到的是“观测均值”，不一定是目标时点的汇总。先界定分组和筛选，再算 Mean、SD、Median 才有意义。

proc means data=sashelp.class
           n mean std median min max maxdec=2;
  class sex;
  var height weight;
run;

回到数据核对：N 是该变量非缺失观测记录数；多条观测不自动代表多个受试者。

每个组、每个访视都要算一遍，有没有更清楚的办法？

当表格需要按治疗组、访视甚至 PARAMCD 输出多种统计量时，逐个手工筛选既繁琐又容易口径不一致。PROC SUMMARY 的 CLASS 与 NWAY 把“按哪些层级汇总”写进程序，OUTPUT 再把统计量交给排版层，分析和展示由此分开。

proc summary data=sashelp.class nway;
  class sex;
  var weight;
  output out=stats(drop=_type_ _freq_)
    n=n mean=mean std=sd median=median;
run;

回到数据核对：检查是否需要保留缺失 CLASS 水平；注意 NWAY、_TYPE_、_FREQ_ 的含义，不要将 _FREQ_ 直接当作分析 N。

PK 浓度常常右偏，为什么只有 Mean 和 SD 不够？

一个很高的浓度就可能把算术均值拉高。Median 描述排序中间的位置，GeoMean 则把倍数变化放到对数尺度上理解。它不是对 Mean 简单开方：只有正值可以直接取 LOG，零值与 BLQ 的处理还会影响有效样本量，详见 PK 浓度统计专题。

proc univariate data=sashelp.class noprint;
  var weight;
  output out=pctl
    pctlpts=25 50 75 pctlpre=p_;
run;

data logdata;
  set sashelp.class;
  if weight>0 then logw=log(weight);
run;
proc means data=logdata noprint;
  var logw;
  output out=gm0 mean=mean_log;
run;
data gm;
  set gm0;
  geometric_mean=exp(mean_log);
run;

回到数据核对：分位数计算方法在不同过程/软件可能不同；几何均值只适用于正值，非正值与缺失要预先按 SAP 定义处理。
