统计汇总：MEANS / SUMMARY / UNIVARIATE

从 n、Mean、SD、Median 到分组统计、分位数、CV 与几何均值；核心是清楚每个统计量从哪些记录计算。

01 基础02 实战03 进阶 / QC
LEVEL 1 · 基础

MEANS：快速获得描述统计

常用统计量为 N MEAN STD MEDIAN MIN MAX；VAR 指定数值变量，CLASS 定义分类层级。

proc means data=sashelp.class
           n mean std median min max maxdec=2;
  class sex;
  var height weight;
run;

检查重点：N 是该变量非缺失观测记录数；多条观测不自动代表多个受试者。

LEVEL 2 · TFL 实战

SUMMARY：NWAY + OUTPUT

PROC SUMMARY 适合直接生成可供 TFL 使用的汇总数据集；NWAY 只保留全部 CLASS 变量组合的统计。

proc summary data=sashelp.class nway;
  class sex;
  var weight;
  output out=stats(drop=_type_ _freq_)
    n=n mean=mean std=sd median=median;
run;

检查重点：检查是否需要保留缺失 CLASS 水平；注意 NWAY、_TYPE_、_FREQ_ 的含义，不要将 _FREQ_ 直接当作分析 N。

LEVEL 3 · 进阶 / QC

UNIVARIATE 分位数 + 几何均值

UNIVARIATE 可指定分位点；几何均值常用对正值先取对数再取均值并反变换。几何 CV 与算术 CV 不一样。

proc univariate data=sashelp.class noprint;
  var weight;
  output out=pctl
    pctlpts=25 50 75 pctlpre=p_;
run;

data logdata;
  set sashelp.class;
  if weight>0 then logw=log(weight);
run;
proc means data=logdata noprint;
  var logw;
  output out=gm0 mean=mean_log;
run;
data gm;
  set gm0;
  geometric_mean=exp(mean_log);
run;

检查重点：分位数计算方法在不同过程/软件可能不同；几何均值只适用于正值，非正值与缺失要预先按 SAP 定义处理。
