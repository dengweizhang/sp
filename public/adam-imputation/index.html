ADaM 填补与衍生方法总览

从日期补值到多重插补、从 BLQ 到删失，按真实工作场景建立可追溯的 ADaM 处理方法地图。

一篇处理“ADaM 中所有常见填补逻辑”的工作索引

本文按实际工作场景覆盖日期/时间、连续型、二分类、检出限、基线、访视、TTE 和敏感性分析等主要类别，尽量系统而非仅列 LOCF。但 ADaM 没有“穷尽所有研究填补算法”的固定清单：任何具体项目都可能追加 SAP 定义的规则。

文中区分三层：① CDISC 规范要求怎样表达与追溯；② CDISC CT 提供哪些受控值；③ 项目 Protocol / SAP / Spec 才决定何时、如何填补。这比照抄某个项目的日期补值逻辑更稳妥。

1. 先分清三类“填补”

类别解释ADaM 里可能看到
缺失数据插补
Imputation		对原本缺少分析值的时间点或终点赋予估计/约定值DTYPE=LOCF/WOCF/BLOCF；MI 衍生数据；NRI 分析响应标记
日期/时间元素填补
Partial date/time		已知部分日期，按预定规则补全年月日或时分秒ASTDT、AENDT、ASTDTF、AENDTF、*TMF
分析值派生
Derivation		原值并非缺失，而是从多个观测生成新的统计量或分析记录DTYPE=AVERAGE/MAXIMUM/MINIMUM/LOV/COPY；BASE、CHG

关键原则：并非所有 DTYPE 非空记录都等于“原始数据缺失”。有些是派生汇总（如 AVERAGE），有些是复制到特定分析时间点（COPY、LOV）。反过来，缺失数据的模型化处理也未必会在 BDS 中显示为一条 DTYPE 记录。

ADaMIG v1.3 §3.1.3 提供日期/时间填补标志命名及取值原则，§4.5.1 则给出 LOCF/WOCF 新增时间点记录示例。这属于数据表达规范，不是必须对所有研究使用 LOCF 的要求。

2. 部分日期与时间：最常见，也最容易影响安全性

在 AE、CM、MH、EX、死亡日期等分析中，可能面对 2026-11、2026、缺少日/时分的日期。必须先判断这项分析为什么需要完整日期，才能选择是否以及如何补值。

场景常见可选策略（非 CDISC 统一规定）必须检查
AE 起始日期缺日可考虑月初/首次给药日等边界规则；也可能通过区间比较避免填补TEAE 分类是否偏向保守；是否跨首次给药；完整日期是否被改动
AE 结束日期缺日可考虑月末/研究结束边界；需防止早于开始日期持续事件、治疗期归属、起止顺序
CM 起止日期按与给药的重叠关系做保守/相应边界判断是否并用药、开始/结束与研究治疗交集
MH 起止日期可能仅用于既往史分类、持续性判断或计算病程不能将所有不完整既往史日期机械补为 01JAN
首次/末次给药时间若需要补值，规则应特别谨慎；有时应保留未知而不强行赋值TEAE、相对日、PK 采血间隔、暴露持续时间是否被影响
时分秒缺失可依据 SAP 约定 00:00、23:59、秒数置零或不填补“只收集到分钟”与“本应收集秒但缺失”不同
完全缺失的日期可能按规则保留缺失、从相关证据推断区间，或设保守分类不得无依据凭空生成精确日

2.1 代表性日期标志：*DTF

来源精度分析日期示意标志（最高填补级别）
2026-11-082026-11-08空（未补）
2026-112026-11-01（假定月初）D：补日
20262026-01-01（假定年初）M：补月，可能同时补日
缺年（有月/日）依据规则补全年份Y：补年

这里“01”仅用于演示某种允许的项目规则。ADaMIG v1.3 表 3.1.3.1 明确说明日期补值标志并不隐含具体的补值算法；例如只缺月时，项目规则可能连日一并重新决定。

时间标志 *TMF：H 代表整个时间被补；M 代表分钟及秒被补；S 代表只补秒。当本来就不收集秒且统一拼成 00，规则与原本需要收集秒而某次缺失不同。是否需要 DTF/TMF 要看相应变量是否确实发生填补。

TEAE 不是先“随便补一个日期”再判断

例如 AE 起始只知道 2026-11，首次给药发生在 11 月 15 日。实际 AE 可能在给药前也可能在给药后；SAP 可要求保守视为 TEAE，也可先判断日期区间。先决定分析问题与保守规则，再衍生日期/标志。不可把“缺失日一律补 01”误说成 CDISC 强制规则。

3. 连续型纵向数据：LOCF 之外还有很多方法

方法是什么典型注意点
LOCF
Last Observation Carried Forward		用上一个合格的非缺失观测值代替缺失访视值合格来源、停药后能否携带、最大间隔，不能默认适用于所有主要分析
BLOCF
Baseline Observation Carried Forward		用非缺失基线观测值代替后续缺失值相当于施加特定缺失后结果假设，可能有偏倚
SOCF
Screening Observation Carried Forward		用筛选期值进行替代筛选期与基线不一定相同
NOCB
Next Observation Carried Backward		用后一个非缺失值回填更早时间点会使用后续信息；不能默认用于前瞻性判定
WOCF
Worst Observation Carried Forward		按受试者已观察到的最差结局替代相关缺失时间点需要明确“最差”的方向和数据范围
BOCF
Best Observation Carried Forward		用截至规定时间点已观察的最佳值填补与 BOC（最佳观测结果）有所区分
POCF
Penultimate Observation Carried Forward		使用倒数第二个合格观测值不同于普通 LOCF
MOV / MOTH分别用指定组的观测均值 / 参照组均值代替需要明确组别、时间点及统计假设
INTERP / EXTRAP已知数据点之间插值 / 超出观测范围外推方法、模型、边界、临床合理性必须预定义
ML最大似然估计方法对应的受控术语不等于“随便用模型预测值填写 AV​AL”

这些是 CDISC ADaM DTYPE 受控术语中可以出现的类型，不是建议全部采用。不同药物、终点与 Estimand 可能会限制乃至不允许某些单值插补。

3.1 现代临床试验中常见的模型处理

策略直观理解ADaM 的可能表达
MMRM（无显式单值填补）使用可观测纵向数据，依赖模型及缺失机制假设进行估计主要分析 BDS 数据可能不新增填补行；模型使用实际可分析观测
MI（Multiple Imputation）多次生成符合模型假设的缺失值，分别分析，再合并估计可有每次插补的编号、数据集/补充变量与合并分析结果；以 Spec 为准
Reference-based MI如 J2R、CIR 等，按预定义参考组轨迹处理某些 ICE 后的缺失敏感性分析的假设、插补数据与结果明确标识
Delta-adjusted / Tipping point改变插补假设或偏移量，评估结论何时翻转方案场景编号、Delta、插补副本、模型结果
Pattern-mixture / Selection model对缺失模式或缺失机制进行建模方法学决定数据准备方式，不能只看 DTYPE 推断模型

分清两层：Estimand 处理停药、救援用药等 ICE 的策略；MI/MMRM 等是估计该目标所用的方法。没有填补记录不代表不需要解释缺失机制。

4. 二分类和复合终点：NRI / Failure 与极端情景

策略典型思路风险点
NRI（Non-responder Imputation）满足规则的缺失响应 / 停药 / 使用救援治疗按“未响应”计哪些情况触发、是否与 ICE 策略一致，不能所有缺失都判失败
Composite failure将某个 ICE（如启动救援治疗）直接纳入失败定义这是终点定义/Estimand 策略，未必是缺失值插补
WC / BC假定最差 / 最佳可能的结局进行分析常用于界限或敏感性情景，非普遍主分析
WOV / WOC / BOC组内最差观测值、受试者最差/最佳观测结果观测范围、严重性/改善方向需固定
Missing category分类缺失另设 “Missing/Unknown” 类别，用于描述性汇总并非赋予某个临床反应值；分母/Unknown 含义必须清楚
示意：减重达标率

若某周评价受试者是否达到 ≥5% 体重下降，真实观测结果、因停药而按复合失败规则判定，以及对真正缺失体重的 NRI，要在 Spec 中区分来源。不能只写一句“缺失=否”，就混淆了终点定义与缺失假设。

5. BLQ、LOD/LLOQ、PK 浓度与实验室指标

低于定量下限（BLQ/BQL）与常规“未采集”不是同一种缺失。尤其 PK / PD 中，它可能影响 AUC、末端消除拟合和剂量–暴露估计。

策略 / DTYPE含义注意事项
LLOQ / HALFLLOQ用定量下限 / 其一半代替需知道每个分析物、实验室与时间对应的真实 LLOQ
LLOD / HALFLLOD用检测下限 / 其一半代替LOD（检出限）与 LOQ（定量限）不是同义词
ULOQ / ULOD用上侧定量/检测界限替代适用规则及高值的方向必须明确
零值替代例如特定 PK NCA 的给药前 BLQ 按 0 处理在给药前、峰前、峰后可能采用不同规则；这不是全局标准
保留缺失 / 排除拟合点不强行给定浓度，按预定义原则处理影响 AUC、Tlast、Lambda_z 及可计算性
模型化删失处理将低于下限的观测作为删失/有限检测信息纳入模型某些 PopPK 方法可使用，不能直接套用 NCA 浓度表替代规则

两个 QC 检查：（1）BLQ 在 SDTM 中如何保留原始定性结果与定量限；（2）ADPC/ADPP 的分析浓度、可分析标志、模型/规则是否一致。不要在 SDTM 原数据上不可逆地覆盖 <LLOQ。

6. 基线、访视窗与派生记录：不全叫插补

场景可能做法为什么不必然属于缺失填补
缺失基线不算 CHG；选择合格的较早观测；按预设均值构建基线；极少数情形另有插补选择基线或构建基线是分析定义；并不保证存在真实缺失值
访视窗口选择根据目标日、实际日、优先级从多个记录选出一个ANL01FL、AVISIT、AWTARGET、AWTDIFF 常体现选取逻辑
Endpoint 记录最近一次合格观测复制到特定端点，例如 DTYPE=LOV有时只是派生的分析端点记录，并非填补缺失访视
汇总派生AVERAGE、MAXIMUM、MINIMUM从观测记录汇总；不一定缺失
PHANTOM创建预设时间点的空分析记录，AVAL 依然缺失增加记录本身并未填出数值
标准化与换算单位转换、正常范围/CTCAE 分级、比例/变化量计算属于衍生，不是自动“缺什么补什么”

ADaMIG v1.3 §4.5.2–4.5.4 提供派生基线、Endpoint、最大/最小值、访视窗和 ANLzzFL 的示例。同一个 AVISIT 出现观察值、LOCF 值和 WOCF 值时，必须使用正确的 DTYPE/分析标志进行筛选，否则分析可能重复计数。

7. 时间到事件：删失不是“填补一个事件日期”

ADTTE 常按方案确定事件发生、删失和起始日，并衍生 AVAL 与 CNSR。例如 PFS 可能因缺少规定的肿瘤评估、启动后续治疗或较长的评估间隔而触发不同删失规则。

删失（Censoring）不是假定患者在删失日发生了事件，也不是简单用“随访末日填补缺失进展日”。事件日期的定义、检测窗口和删失规则都来自 SAP。

示意：PFS

研究结束时未观察到进展/死亡，可能根据最后一次符合要求的充分评估日期设定删失。该规则不能简单等同于把缺失的进展日期补为最后访视日期；不同的缺失评估情景需分别处理。

9. 从 SDTM 到 ADaM：什么叫可追溯？

① 保留来源保留需要的 --DTC、--SEQ、分析日期/分析值及源数据路径；避免覆盖收集值
② 保留规则在 Spec/Define 明确逻辑、变量、方法、边界、缺失适用条件和项目假设
③ 保留身份对于新生成的记录，记录 DTYPE、AVISIT、ANLxxFL 和必要的来源链接
④ 保留验证编写 QC 场景，验证边界、同日给药、部分缺失、多个候选来源及不同分析版本

10. ADaM 填补逻辑 QC 清单与面试题

Q1. 缺失的 AE 开始日期一定补为当月 1 日吗？

不是。先看 SAP 目的（如 TEAE 归类），根据部分日期与首次给药的关系采用项目规则；CDISC 规定的是补值标志的表达，不规定一律月初。

Q2. DTYPE=AVERAGE 是否代表“缺失值插补”？

未必。它通常表示基于多个观测值派生汇总记录，可能完全没有缺失。

Q3. NRI 是不是必须把 AVAL 改成 0？

不一定。要看二分类参数的编码（0/1、Y/N 或其他）和是否采用新增记录、参数/标志，不能简单以数值 0 概括所有情况。

Q4. MMRM 必须产生所有缺失访视的填补行吗？

通常不需要。MMRM 可基于观察记录和模型假设进行推断。若 SAP 另有敏感性分析或辅助推导，则按相应 Spec。

Q5. BLQ 值能否全部补 0？

不能。应区分给药前、峰前、峰后以及 NCA/PopPK 等分析目的，按照具体规则与定量限处理。

Q6. TTE 中 CNSR=1 是否代表把失访后的事件日期补出来？

不代表。删失记录了截至所知时点的事件观察信息，不是将未知事件时间制造成一个已发生事件。

实际项目建议建立的审核矩阵

检查项应该记录
何时触发变量缺失形式、分析人群、评价时点、停药/救援治疗条件
如何计算填补方向、来源优先级、边界日/时间、候选记录与相同值决胜规则
如何标识DTYPE、DTF/TMF、ANLxxFL、原始与分析日期、分析记录层级
如何检验样例、边界用例、独立 QC、TFL 分母/人群/参数一致性

面试时能回答“为什么采用某种缺失策略、在 ADaM 怎样表达、有什么分析风险”，比只背 LOCF 的全称有价值。
