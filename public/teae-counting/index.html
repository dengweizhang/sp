TEAE 表怎么数人头？从 ADSL、ADAE 到 n (%)

一个人两次恶心、一次头痛，一张 TEAE 表应该把他算几次？先确定每一行在回答什么，再从受试者粒度搭表。

先把分母和分子放到同一人群

假设 Shell 要求按实际治疗组列出安全性人群，同时另出一张预先定义的亚组表。先从 ADSL 取符合条件的受试者，得到每张表、每个治疗组的分母 Big N。再把符合分析条件的 ADAE 记录和这批受试者匹配，按每行的定义计算 n。没有 TEAE 的受试者仍在分母里。同一个人可以出现在两张表里，每张表分别计算。

下面是模拟数据。教学示例假定 ADAE 已根据研究规则衍生 TRTEMFL，这里直接用 TRTEMFL='Y' 选事件。实际项目先确认分析集、分组变量、分析时段和事件筛选条件。

受试者实际治疗组是否属于亚组事件
S01A是恶心 2 条、头痛 1 条，均为 TEAE
S02A是无 AE
S03A否头痛 1 条，为 TEAE
S04B是恶心 1 条，为 TEAE
S05B否给药前头痛 1 条，未纳入 TEAE

同一个人在哪些行里各算一次？

在 A 组安全性人群中，S01 有三条 TEAE，在「至少一项 TEAE」行计 1 人，在「恶心」行和「头痛」行各计 1 人。S03 也计入「头痛」，所以 A 组头痛是 2 / 3 = 66.7%。在按 SOC/PT 汇总的表里，SOC 行在该 SOC 内按人去重，PT 行在该 SOC/PT 内按人去重。一个人在同一 SOC 下有多个 PT 时，各 PT 人数之和可能大于 SOC 人数。若 Shell 另列事件数，才分别按符合条件的事件记录计数。

如果同一 PT 要按最高等级分布，先在「人群 × 治疗组 × 受试者 × PT（如按 SOC/PT 展示则含 SOC）」内确定最高等级，再统计各等级人数。总体行、SOC 行各有自己的取最高等级范围。等级缺失的处理按项目规则走。

两步 SAS 实现，怎么验证？

先得到每个「人群 × 治疗组 × 受试者」的事件标志，再对 0/1 标志求和。左连接保留 S02 和 S05，因此有分母、无事件的组也能得到 0。下面的固定 PT 仅用于复现示例，实际项目通常按目标 SOC/PT 粒度构造明细，并用 Shell 补齐需要展示的行列。

展开自包含 SAS 示例 
data adsl_demo;
  input usubjid $ trta $ saffl $ cohfl $;
  datalines;
S01 A Y Y
S02 A Y Y
S03 A Y N
S04 B Y Y
S05 B Y N
;
run;

data adae_demo;
  input usubjid $ aept $ trtemfl $;
  datalines;
S01 Nausea Y
S01 Nausea Y
S01 Headache Y
S03 Headache Y
S04 Nausea Y
S05 Headache N
;
run;

data population_members;
  set adsl_demo;
  where saffl='Y';
  length population $6;
  population='Safety';
  output;
  if cohfl='Y' then do;
    population='Subset';
    output;
  end;
  keep population trta usubjid;
run;

proc sql;
  create table subject_flags as
  select p.population, p.trta, p.usubjid,
         max(case when a.trtemfl='Y' then 1 else 0 end) as any_teae,
         max(case when a.trtemfl='Y' and a.aept='Nausea'
                  then 1 else 0 end) as nausea,
         max(case when a.trtemfl='Y' and a.aept='Headache'
                  then 1 else 0 end) as headache
  from population_members as p
  left join adae_demo as a on p.usubjid=a.usubjid
  group by p.population, p.trta, p.usubjid;

  select population, trta, count(*) as big_n,
         sum(any_teae) as n_any, sum(nausea) as n_nausea,
         sum(headache) as n_headache
  from subject_flags
  group by population, trta;
quit;

教学代码使用虚构数据，未在 SAS 环境执行。手工复核时，给 S01 再加一条恶心，恶心仍只计同一受试者 1 人。去掉 S02 会改变分母。亚组 B 的分母只有 1，核对输出表头和百分比时应使用同一个人群。若某组 N=0，百分比不可计算，按 Shell 约定显示。
