01TFL n (%) 多出空格

根因：PUT(...,pctfmt.) 可能返回前导空格，|| 原样保留；COMPRESS(COUNT) 不会清理右边的内容。

/* 推荐：COUNT 与括号间固定一个空格 */
catx(' ',
     compress(COUNT),
     put(input(compress(PCT),best.),pctfmt.)
)

注意：CATX 不删除括号内部的对齐空格。当前 pctfmt. 把 0% 显示为空白；99.95-high="(100)" 会把所有 ≥99.95 的值（包括超过 100）都显示为 100。

02PROC FORMAT：VALUE / PICTURE / INVALUE

一句话：VALUE 做值到标签的映射；PICTURE 用数字模板控制显示；INVALUE 定义读取数值的输入格式。格式改变显示，不改变原值。

proc format;
    value $yn 'Y'='Yes' 'N'='No';
    invalue ynnum 'Yes'=1 'No'=0;
    picture pctfmt (round)
        0             = ' '       (noedit)
        0<-<0.1       = '(<0.1)'  (noedit)
        0.1-<9.95     = '09.9)'   (prefix='(  ')
        9.95-<99.95   = '00.0)'   (prefix='( ')
        99.95-high    = '(100)'  (noedit);
run;

记住：PREFIX 是前缀，NOEDIT 是固定文字，ROUND 控制格式化舍入；此 pctfmt. 仅适用于百分比不超过 100 的业务。

03INPUT 与 PUT：方向相反

INPUT：字符按 Informat 读入（通常转数值）。PUT：值按 Format 输出为字符。FORMAT 语句只修改变量显示方式。

data _null_;
    n = input('12.5',best.); /* 字符 -> 数值 */
    c = put(n,5.1);         /* 数值 -> 字符 */
    format n 5.1;           /* n 仍然是数值 */
    putlog n= c=;
run;

本次宏：INPUT(PCT,BEST.) 先把字符型百分比转数值，再由 PUT(...,pctfmt.) 生成显示文本；如果 PCT 本身是数值型，就不必先 INPUT。

05ODS Unicode、上标和下标

记住：007E=~，0025=%。下面是常用十六进制码和 ODS 控制语法，实际显示取决于字体、ODS 输出目标与版本。

码位字符用途

ods escapechar='^';
title "About ^{unicode 007E} ^{unicode 0025}";
title2 "mm^{super 2} and H^{sub 2}O";
/* 若项目设置 ods escapechar='~'，
   则将以上 ^{...} 改为 ~{...} */

注意：^{unicode ...} 与 ^{super ...} 属于 ODS inline formatting，不是 PROC FORMAT；ODS LISTING 目的地不支持相同的 ODS inline 表现。RTF 和 TAGSETS.RTF 需要分别验证。

06PROC REPORT：多个 COL 合并为组标题

核心：在 COLUMN 里用 ("组标题" col3 col4 ...)，形成横跨多个列的上层标题；DEFINE ... / GROUP 则是对行记录分组，二者不是一回事。官方 COLUMN 语法 ↗

proc report data=final nowd missing;
  column page usubjid col1 col2
         ("Alcohol History" col3 col4 col5 col6)
         ("Smoking History" col7 col8 col9 col10);
  define page / order noprint;
  define usubjid / order "Subject ID";
  /* 其余 col1-col10 按表壳分别 DEFINE */
run;

你截图的重点：红框使用两个括号分别给 Alcohol History（col3–6）和 Smoking History（col7–10）做跨列标题；其中 ~R'\qc\brdrb...' 属于 RTF 专用排版控制，不是跨列分组必需的语法。

07正则表达式：PRXMATCH / PRXCHANGE

PRXMATCH 查符合模式的位置（未匹配返回 0）；PRXCHANGE 按模式替换。优先掌握 ^、$、\d、{n}、()、[]、+ 与替换中的 $1。

/* 完整日期 YYYY-MM-DD */
ok = prxmatch('/^\d{4}-\d{2}-\d{2}$/',strip(dt));

/* 任意连续空格 -> 一个空格 */
clean = prxchange('s/ +/ /',-1,strip(raw));

/* 从“某参数 (mg)”提取括号里的单位 */
unit = strip(prxchange('s/.*\(([^)]*)\).*/$1/',1,param));

边界：最后一个示例只适合包含括号的文本，未匹配时 PRXCHANGE 可能返回原文，应先判断；部分 SAS 环境不接受 PRX 模式尾部 /u 修饰符。日期插补仍以 SAP/Spec 为准。

08ODS RTF：标题、分页与文件关闭

先分清：TITLE 是 ODS 标题；COMPUTE BEFORE _PAGE_ 的 LINE 属于 PROC REPORT 报表内容，可能每页重复；BREAK AFTER ... / PAGE 是主动分页。

ods listing close;
ods escapechar='^';
ods rtf file="report.rtf";
proc report data=sashelp.class nowd;
  column name sex age;
  define name / display;
  define sex / display;
  define age / display;
run;
ods rtf close; /* 开 ODS RTF，关 ODS RTF */
ods listing;

排查：空白页除了 HEADSKIP，还要查脚注、末尾段落、余量、手动分页与 FINAL 中的空白占位行；使用 ODS TAGSETS.RTF 时要对应 ODS TAGSETS.RTF CLOSE，不能混关。
