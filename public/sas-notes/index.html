01TFL n (%) 多出空格

根因：PUT(...,pctfmt.) 可能返回前导空格，|| 原样保留；COMPRESS(COUNT) 不会清理右边的内容。

/* 推荐：COUNT 与括号间固定一个空格 */
catx(' ',
     compress(COUNT),
     put(input(compress(PCT),best.),pctfmt.)
)

注意：CATX 不删除括号内部的对齐空格。当前 pctfmt. 把 0% 显示为空白；99.95-high="(100)" 会把所有 ≥99.95 的值（包括超过 100）都显示为 100。

02PROC FORMAT：VALUE / PICTURE / INVALUE

一句话：VALUE 做值到标签的映射；PICTURE 用数字模板控制显示；INVALUE 定义读取数值的输入格式。格式改变显示，不改变原值。

proc format;
    value $yn 'Y'='Yes' 'N'='No';
    invalue ynnum 'Yes'=1 'No'=0;
    picture pctfmt (round)
        0             = ' '       (noedit)
        0<-<0.1       = '(<0.1)'  (noedit)
        0.1-<9.95     = '09.9)'   (prefix='(  ')
        9.95-<99.95   = '00.0)'   (prefix='( ')
        99.95-high    = '(100)'  (noedit);
run;

记住：PREFIX 是前缀，NOEDIT 是固定文字，ROUND 控制格式化舍入；此 pctfmt. 仅适用于百分比不超过 100 的业务。

03INPUT 与 PUT：方向相反

INPUT：字符按 Informat 读入（通常转数值）。PUT：值按 Format 输出为字符。FORMAT 语句只修改变量显示方式。

data _null_;
    n = input('12.5',best.); /* 字符 -> 数值 */
    c = put(n,5.1);         /* 数值 -> 字符 */
    format n 5.1;           /* n 仍然是数值 */
    putlog n= c=;
run;

本次宏：INPUT(PCT,BEST.) 先把字符型百分比转数值，再由 PUT(...,pctfmt.) 生成显示文本；如果 PCT 本身是数值型，就不必先 INPUT。

04CAT / CATS / CATX：怎么拼接

函数规则示例（_ 代表空格）
CAT(a,b)保留两端空格，无分隔符_A__B_
CATS(a,b)删首尾空格，无分隔符AB
CATX(' ',a,b)删首尾空格，加入指定分隔符A_B

示例输入：a=' A '、b=' B '。速记：CAT 保留，CATS 清理，CATX 清理后加分隔符。三个函数都不删除参数内部空格；本次 n (%) 用 CATX。
