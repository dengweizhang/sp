01TFL n (%) 多出空格

根因：PUT(...,pctfmt.) 可能返回前导空格，|| 原样保留；COMPRESS(COUNT) 不会清理右边的内容。

/* 推荐：COUNT 与括号间固定一个空格 */
catx(' ',
     compress(COUNT),
     put(input(compress(PCT),best.),pctfmt.)
)

注意：CATX 不删除括号内部的对齐空格。当前 pctfmt. 把 0% 显示为空白；99.95-high="(100)" 会把所有 ≥99.95 的值（包括超过 100）都显示为 100。

02PROC FORMAT：VALUE / PICTURE / INVALUE

一句话：VALUE 做值到标签的映射；PICTURE 用数字模板控制显示；INVALUE 定义读取数值的输入格式。格式改变显示，不改变原值。

proc format;
    value $yn 'Y'='Yes' 'N'='No';
    invalue ynnum 'Yes'=1 'No'=0;
    picture pctfmt (round)
        0             = ' '       (noedit)
        0<-<0.1       = '(<0.1)'  (noedit)
        0.1-<9.95     = '09.9)'   (prefix='(  ')
        9.95-<99.95   = '00.0)'   (prefix='( ')
        99.95-high    = '(100)'  (noedit);
run;

记住：PREFIX 是前缀，NOEDIT 是固定文字，ROUND 控制格式化舍入；此 pctfmt. 仅适用于百分比不超过 100 的业务。

03INPUT 与 PUT：方向相反

INPUT：字符按 Informat 读入（通常转数值）。PUT：值按 Format 输出为字符。FORMAT 语句只修改变量显示方式。

data _null_;
    n = input('12.5',best.); /* 字符 -> 数值 */
    c = put(n,5.1);         /* 数值 -> 字符 */
    format n 5.1;           /* n 仍然是数值 */
    putlog n= c=;
run;

本次宏：INPUT(PCT,BEST.) 先把字符型百分比转数值，再由 PUT(...,pctfmt.) 生成显示文本；如果 PCT 本身是数值型，就不必先 INPUT。

ods escapechar='^';
title "About ^{unicode 007E} ^{unicode 0025}";
title2 "mm^{super 2} and H^{sub 2}O";

06PROC REPORT：跨列标题与 RTF 排版

问题从哪里来？一份 Listing 中，Alcohol History 需要横跨 col3–col6，Smoking History 需要横跨 col7–col10；同时组标题还要居中、带底边框。其实这是两件事：哪些列属于一组，以及这一组如何显示。

先决定表头结构：COLUMN 的括号

proc report data=final nowd missing
  style(report)=[outputwidth=100%]
  style(header)=[just=center asis=on]
  style(column)=[just=left asis=on];

  column page usubjid col1 col2
    ("Alcohol History" col3 col4 col5 col6)
    ("Smoking History" col7 col8 col9 col10);

  define page / order noprint;
  define usubjid / order "Site / Subject ID"
    style(column)=[cellwidth=6%];
  define col3 / display "Alcohol Use Within 6 Months?"
    style(column)=[cellwidth=8%];
  /* 其他 col1-col10 逐列 DEFINE，按 Shell 设置宽度 */
run;

理解：("标题" col3 col4 ...) 只建立“跨列上层表头”，不会让数据行分组；DEFINE xx / GROUP 或 ORDER 才影响行的组织方式。列宽加起来须适配页面可用宽度，不能只看每一列本身。

再决定显示样式：STYLE 比 RTF 控制字更通用

设置解决什么问题
style(report)报表整体宽度（如 outputwidth=100%）
style(header)所有层级标题的对齐、字体、边框
style(column)数据单元格对齐、保留空格等
DEFINE ... style(column)针对单独一列的 cellwidth、对齐等
split='|'让列标题中的 | 作为换行标记
/* 优先用样式属性表达需求 */
style(header)=[just=center
               borderbottomstyle=solid
               borderbottomwidth=1pt
               borderbottomcolor=black]
style(column)=[just=left asis=on];

注意：报表级的 style(header) 可能同时影响跨列标题和各列标题。若需要不同层级采用不同边框，要结合 Tagset、模板或分层标题实际输出检查；不要默认同一条 STYLE 只作用于组标题。

为什么旧宏里会出现 ~R'...'？

你截图中的 ~R'\qc\brdrb\brdrs\brdrw16' 属于向 RTF 注入原生段落/边框控制字，不是 PROC REPORT 必需的语法。

ods escapechar='~';
/* 旧项目写法：保留原意，需在同版本 TAGSETS.RTF 验证 */
column page usubjid col1 col2
 ("~R'\qc\brdrb\brdrs\brdrw16' Alcohol History"
   col3 col4 col5 col6)
 ("~R'\qc\brdrb\brdrs\brdrw16' Smoking History"
   col7 col8 col9 col10);

\qc 表示段落居中；\brdrb 为下边框；\brdrs 为单实线；\brdrw16 为 16 twips，约 0.8 pt。这是 RTF 特有语法，不能原样期待在 PDF 或 EXCEL 中生效。SAS 文档也存在 ~R/RTF'...' 的目的地限定形式，具体支持情况须按环境测试。

最后检查：跨列分组是否覆盖正确列数、标题是否溢出、线条是否重复、第一页和最后一页是否异常。ODS TAGSETS.RTF 打开后用 ODS TAGSETS.RTF CLOSE 关闭，不与普通 ODS RTF 混用。参考 SAS PROC REPORT COLUMN。

07正则表达式：PRXMATCH / PRXCHANGE

PRXMATCH 查符合模式的位置（未匹配返回 0）；PRXCHANGE 按模式替换。优先掌握 ^、$、\d、{n}、()、[]、+ 与替换中的 $1。

/* 完整日期 YYYY-MM-DD */
ok = prxmatch('/^\d{4}-\d{2}-\d{2}$/',strip(dt));

/* 任意连续空格 -> 一个空格 */
clean = prxchange('s/ +/ /',-1,strip(raw));

/* 从“某参数 (mg)”提取括号里的单位 */
unit = strip(prxchange('s/.*\(([^)]*)\).*/$1/',1,param));

边界：最后一个示例只适合包含括号的文本，未匹配时 PRXCHANGE 可能返回原文，应先判断；部分 SAS 环境不接受 PRX 模式尾部 /u 修饰符。日期插补仍以 SAP/Spec 为准。

08ODS RTF：标题、分页与文件关闭

先分清：TITLE 是 ODS 标题；COMPUTE BEFORE _PAGE_ 的 LINE 属于 PROC REPORT 报表内容，可能每页重复；BREAK AFTER ... / PAGE 是主动分页。

ods listing close;
ods escapechar='^';
ods rtf file="report.rtf";
proc report data=sashelp.class nowd;
  column name sex age;
  define name / display;
  define sex / display;
  define age / display;
run;
ods rtf close; /* 开 ODS RTF，关 ODS RTF */
ods listing;

排查：空白页除了 HEADSKIP，还要查脚注、末尾段落、余量、手动分页与 FINAL 中的空白占位行；使用 ODS TAGSETS.RTF 时要对应 ODS TAGSETS.RTF CLOSE，不能混关。

09PK 浓度：Mean / CV% / GeoMean / GeoCV%

算术 CV% = 100 × SD / Mean；GeoMean = exp[Mean(ln x)]；GeoSD = exp[SD(ln x)]；GeoCV% = 100 × √{exp[SD(ln x)²]−1}。

/* 对正值浓度取 ln 后，用 std(logx) 计算 */
geomean = exp(mean_log);
geosd   = exp(sd_log);
geocv   = 100*sqrt(exp(sd_log**2)-1);

注意：原项目浓度 Shell 涉及 N、n、n of BLQ、Mean、SD、CV%、Median、Min、Max、GeoMean、GeoSD、GeoCV%；n 和分母 N 不同，BLQ 与几何统计必须先明确方案规则。查看完整含义、算例和 TFL/SAS 代码 ↗
