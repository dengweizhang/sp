临床试验设计：从随机双盲到 SAD/MAD

从“受试者如何分组、接受什么治疗、何时评价”出发，建立可用于 Protocol 阅读、SDTM/ADaM 编程与 SP 面试的试验设计框架。

先记住一句话

平行组、随机、双盲、安慰剂对照是四个不同维度，可以同时出现。例如“Ⅱ期、多中心、随机、双盲、安慰剂对照、平行组研究”，就是把研究阶段、中心、分配方式、盲态、对照和结构拼在一起。

本文的“最常见”指实务中需要优先掌握的典型设计，而不是所有临床试验类型的频率排行榜。ICH E9 明确将平行组列为确证性试验最常见的设计。

1. 一项试验由哪些设计维度组成？

不要把试验设计理解为只有“随机双盲”四个字。实际 Protocol 可以从以下七个维度拆解。

维度常用选项核心问题
研究类型干预性 / 观察性是否由研究方案指定干预？
研究结构单臂、平行、交叉、析因、序贯受试者按什么路径接受干预？
分配方式随机 / 非随机 / 不适用如何决定进入哪个组或序列？
盲法开放、单盲、双盲等谁不知道治疗分配信息？
对照类型安慰剂、阳性、剂量、无治疗、外部用什么作为比较依据？
评价目的安全性/PK/PD、探索、确证；优效、非劣效、等效研究要得出什么结论？
执行方式单/多中心、固定/适应性、队列递增等试验在时间和中心上如何实施？

另一个经常混淆的维度是Ⅰ、Ⅱ、Ⅲ、Ⅳ期（Phase）：它描述临床开发阶段，不是平行组或交叉设计的同义词。Ⅰ期也可能随机、双盲和安慰剂对照；Ⅲ期也不必然采用完全相同的结构。

ICH E8(R1) 还会按研究目的区分临床药理（Human Pharmacology）、治疗探索（Therapeutic Exploratory）、治疗确证（Therapeutic Confirmatory）等。研究阶段与研究目的相关，却不是简单的一一对应。

2. 五种常见研究结构：受试者如何走完整个试验？

ClinicalTrials.gov 的干预模型包括 Single Group、Parallel、Crossover、Factorial、Sequential。以下以简化示意讲解，实际实施需要服从 Protocol。

2.1 平行组（Parallel-group）

受试者在同一研究阶段分别接受不同治疗，各自沿本组流程完成观察。它是确证性试验中非常常见的结构。优点是容易比较同期治疗组；要处理治疗组、分层因素、随机比、失访及缺失数据。

2.2 交叉（Crossover）

同一受试者依次接受多种治疗，可能通过自身对照减少个体差异。经典例子是两治疗、两周期、两序列（2×2 crossover）：AB 与 BA。通常需要考虑洗脱期（Washout），也要评估周期、序列及残留效应；对于病情快速进展或药物作用长期不可逆的情形往往不合适。

2.3 单臂（Single-arm / Single-group）

没有研究内并行的对照治疗组。它可能出现在剂量探索、早期肿瘤研究或某些罕见病研究。单臂不等于单中心，也不等于开放标签，尽管实际研究中经常同时出现。

2.4 序贯分配（Sequential assignment）

后续队列的安排依赖前面预设的里程碑，例如审阅安全数据后开放下一剂量队列。注意：ClinicalTrials.gov 的 Sequential Intervention Model 与统计学的 Group Sequential Design（群序贯设计）不是同一个术语。后者主要讨论预设中期分析及停止边界。

2.5 析因（Factorial）

同时研究多个干预因素及其组合，例如 A、B 两个因素各设有/无两种水平，形成四种组合。应关注因素间交互作用，不是把四种治疗随意放在一起就自动成为析因设计。

3. 随机化（Randomization）到底解决什么问题？

随机化是使用随机机制决定受试者进入哪个组、队列内分配哪个治疗、或交叉试验进入哪个序列。其作用是减少选择偏倚，并在概率意义上促进组间可比性；随机化并不能保证每个基线指标恰好相等。

常见方式如何理解SP 应关注
简单随机
Simple		每次按给定概率分配，如 1:1随机比；小样本不一定人数恰好对半
区组随机
Block		在区组内按预定规则平衡分配区组大小可能保密；不要从数据反推盲底
分层随机
Stratified		按中心、疾病程度等因素分层分配分层因素如何入分析模型、TFL
整群随机
Cluster		随机单位是中心/病区等群组，而不是每个个体不能忽略群内相关性

不要混淆三个概念：Randomization（随机生成分配）≠ Allocation Concealment（入组前防止预知分配结果）≠ Blinding（给药后哪些角色不知道实际治疗）。一项研究可以随机但开放标签，也可能在非随机情形下采用部分盲态评价。

临床常见 IRT/IWRS 系统负责随机化及药物分配管理。对于统计编程，必须遵守盲态数据权限：盲态阶段不能通过 TRT、药盒号或分组衍生意外泄露治疗分配。具体流程以项目盲态计划为准。

4. 开放、单盲、双盲：到底“谁不知道”？

描述含义不能直接推出
开放标签
Open-label		治疗身份未对相关人员实施盲法不等于没有随机化或没有对照
单盲
Single-blind		至少有一类相关角色不知道治疗分配不能单凭“单盲”就断定一定是受试者不知情
双盲
Double-blind		至少两类指定角色保持盲态；典型包括受试者和研究者不等于所有工作人员、统计师或程序员都绝对不知情
三盲 / 四盲
Triple / Quadruple		更多指定角色保持盲态没有统一到所有机构都完全相同的角色组合

ClinicalTrials.gov 会进一步记录谁被盲：Participant、Care Provider、Investigator、Outcomes Assessor。所以复盘方案时，最好回答“哪些角色盲、如何维持盲态、什么时候揭盲”，而不只背双盲这个名词。

维持盲法可能需要匹配安慰剂、双模拟（Double-dummy）等方案；必要时可能发生紧急揭盲。双模拟不是一种新的随机方式。不同配方或给药途径难以做出外观一致的盲法时，可能采用双模拟方案。

面试高频问题

“随机、双盲和安慰剂对照有何区别？”——随机回答如何分配；双盲回答谁不知道分配结果；安慰剂对照回答拿什么比较。这三个属性可以同时存在，也可以彼此独立。

5. 对照方式：为什么要有对照组？

ICH E10 说明，对照用于尽量区分治疗效应与疾病自然变化、其他治疗、观察者或受试者预期等影响。不同对照的适用性和伦理要求不同。

对照类型概念典型注意点
安慰剂
Placebo		不含研究药物活性成分的对照伦理许可、背景标准治疗、盲态维持
阳性 / 活性
Active control		与现有有效治疗比较比较目标是优效还是非劣效？
剂量对照
Dose comparison		比较同种药物不同剂量或方案暴露–反应、剂量组如何定义
无治疗
No-treatment		对照组不接受试验干预可能难以维持盲态，需考虑伦理与偏倚
外部 / 历史
External / Historical		引用试验外部或以往患者资料比较人群差异、混杂偏倚、可比性

优效、非劣效、等效不是三种“对照方式”

Superiority（优效）旨在证明某治疗优于对照；Non-inferiority（非劣效）关注不劣于预先规定的界值；Equivalence（等效）要求差异位于预设双侧等效界值内。它们属于比较目标与假设，应结合主要终点、检验框架和置信区间判断，不能只看 P 值。

特别注意：PK 生物等效性研究中的等效性评价有专门的监管标准，不宜与所有临床疗效等效试验混为一谈。

6. SAD / MAD 试验到底是怎么一步一步做的？

这部分对开展过早期临床研究的 SP 尤其重要。SAD（Single Ascending Dose）是逐队列的单次给药剂量递增；MAD（Multiple Ascending Dose）是逐队列的多次给药剂量递增。二者描述的是给药与递增策略，不是随机、双盲或平行/交叉的替代词。

Step 01筛选与入组满足入排标准，完成基线安全检查
Step 02队列内分配和给药可能设置研究药 / 安慰剂分配；FIH 可能包含哨兵给药
Step 03采集 PK / PD / 安全性实际给药时间、浓度时间点、AE、LB、EG、VS 等
Step 04预设安全性审阅评估停药、递增、重复当前剂量或调整方案的条件
Step 05下一队列或后续研究部分只有满足方案条件才推进；不能假定必然升到最高剂量

SAD 与 MAD 对比

问题SADMAD
主要给药特征每名受试者通常在对应队列接受单次给药在对应队列按方案进行多次给药
核心 PK 关注单次暴露、剂量比例性、消除稳态暴露、蓄积、峰谷浓度
风险控制递增规则、哨兵给药、观察窗口重复给药耐受性、蓄积风险、递增规则
SP 关注点队列、实际剂量、给药后采样相对时间给药日、周期与时间点、稳态指标、给药依从性

两个容易说错的点：① SAD 中“一个剂量队列”不意味着研究只有一组，队列内部也可以随机分配活性药与安慰剂；② 剂量递增的“Sequential Cohorts”不自动等于统计学上的 Group Sequential 检验。

7. 进阶设计：知道名字，还要知道边界

类型核心特征SP 关注
适应性设计
Adaptive		依据预设规则利用积累数据对试验某些方面进行调整，如样本量重估、剂量/治疗组调整中期分析权限、预设调整规则、版本/队列、错误率控制
群序贯设计
Group sequential		预设多次正式中期分析及停止边界分析时点、统计界值、提前停止规则；与队列递增不同
篮式研究
Basket		某治疗跨多个疾病或肿瘤亚型探索按癌种/亚组的分析集与效应解释
伞式研究
Umbrella		单一疾病下评价多个治疗方案，常依据标志物等分组分层、亚研究、共享对照与方案版本
平台研究
Platform		在持续性框架下允许治疗方案进入、退出同期对照、入组时期差异、方案修订

Enrichment		选择更可能观察到治疗作用的目标受试者标志物/特定亚群、入组定义、外推性

不是所有“做了中期分析”就属于适应性设计；FDA 强调适应规则须经过事先计划，并管理统计推断和操作偏倚风险。Basket、Umbrella、Platform 属于主方案（Master Protocol）常见框架，但彼此不能互换。

8. 站在 SP 角度：试验设计最后体现在哪里？

这里是最需要掌握的部分。理解设计后，才能知道为什么同一个变量在不同项目不能照搬衍生逻辑。

层级典型位置核查重点
计划设计TS / TA / TE / TV计划分组、Element、Epoch、计划访视与方案概况
受试者实际路径DM / SE / SV / DS / EX实际 Arm、进入/结束各阶段、访视及用药暴露
受试者级分析ADSL随机化/分析集、基线、计划与实际治疗、队列分组
疗效与安全ADAE / ADLB / ADVS / ADTTE 等分析时段、治疗组、基线、事件归属、研究终点
PK / PDADPC / ADPP 等实际采样时间、给药时间、分析物、周期、剂量组
报表层TFL分组列、分析集、统计模型、跨周期和亚组汇总规则

平行组 vs 交叉设计，编程逻辑的核心差别

平行组一般重点核对受试者所属治疗组与组间比较；交叉设计除了受试者身份，还要识别Sequence、Period、每个 Period 的实际治疗及周期特异的基线/终点，避免把两个周期当成两名独立受试者统计。

在 ADaM 中，TRT01P / TRT01A、TRT02P / TRT02A 等属于可能的期间治疗表示方式，不是看到两个剂量组就自动需要 TRT02*。实际使用的变量与分析结构须按 ADaMIG 及项目 ADaM Spec。

为什么 TA、TE、TV、SE 不能混在一起？

CDISC Trial Design Model 关注的是计划如何开展：TA 描述计划 Arm 与 Element 的顺序，TE 描述 Element，TV 描述计划访视；与之对应，受试者层的 SE 记录实际经历的 Element，SV 记录实际访视。计划 ≠ 实际。另外，SDTM 的 TA 指 Trial Arms，不是 Therapeutic Area（治疗领域）。

按设计类型思考 QC
  • 随机双盲：随机化日期、盲态权限、计划/实际治疗、揭盲后 TFL 分组依据。
  • 交叉：序列与周期、洗脱期、分期治疗、给药时间与采样间隔。
  • SAD/MAD：队列开放顺序、剂量递增、哨兵给药、MAD 多日给药与稳态采样。
  • 开放单臂：没有随机对照不意味着没有分析集；重点核对人群和研究终点。
  • 适应性 / 主方案：不同方案版本、亚研究、阶段/队列、分析时点及同期对照。

9. 面试怎么讲：先完整描述一项研究

推荐记住这个顺序：阶段与人群 → 结构 → 随机化 → 盲法 → 对照 → 给药/访视安排 → 主要终点 → 编程职责。

示例 A · 早期临床 SAD/MAD（仅为通用示例）

“这个项目是一项Ⅰ期健康受试者研究，采用单次和多次递增给药部分，按队列推进，并依据预设安全性审阅规则决定是否进入下一剂量水平。部分队列内可能随机分配研究药与安慰剂。主要评价安全性、耐受性以及 PK/PD。我负责相关的 ADSL、ADEX、ADPC/ADPP 和安全性 TFL，重点核查队列、实际给药剂量、给药时间与 PK 采样窗口。”

示例 B · 随机双盲平行组（仅为通用示例）

“这是一项多中心、随机、双盲、安慰剂对照、平行组研究。受试者按预设比例随机分到试验药或对照组，按对应方案给药并完成随访；主要终点取决于研究疾病。编程工作需要同时区分计划与实际治疗、主要分析集、基线和关键终点，保证揭盲后 TFL 与 SAP 规定一致。”

示例 C · 两周期交叉 PK 研究（仅为通用示例）

“这项研究采用两治疗、两周期、两序列交叉设计，受试者随机进入 AB 或 BA 序列，中间按方案设置洗脱期。分析时需要同时识别受试者、Sequence、Period、Treatment，并处理各周期的给药与采样关系，而不能像平行组一样只按一种治疗归类整个受试者。”

六道适合复习的追问题

Q1. 一项双盲试验一定随机吗？

不一定。盲态和随机化属于两个不同维度，虽然实际研究中经常一起采用。

Q2. 随机开放标签研究算 RCT 吗？

如果随机分配到不同干预组并进行对照，可以是随机对照试验；开放标签不妨碍随机化。

Q3. AB/BA 交叉设计随机分配的是什么？

通常是治疗序列（Sequence）。每名受试者在不同周期接受不同治疗，因此 SP 必须考虑 Period 与序列。

Q4. SAD/MAD 是不是一种固定的随机双盲设计？

不是。它们描述剂量递增与给药策略。研究可另行采用随机、开放或双盲、安慰剂对照等安排，须核对方案。

Q5. “Sequential Assignment”是不是群序贯统计设计？

不是。前者通常描述队列/干预安排基于前期里程碑推进；后者强调预设中期统计检验与停止界值。

Q6. 在 ADaM 里为何不能只保留一个 TRT01A？

对多周期交叉或转换治疗的试验，仅有一个受试者级治疗字段可能不足以表达每周期的实际治疗。是否需要周期特异字段或记录级治疗变量取决于数据结构与 SAP/Spec。
